# 中国马拉松成绩整理助手（本地原型）

本人在官网完成查询及滑块验证后，手动点击扩展读取当前页已展示的成绩，生成项目已有跑史导入器可核对的 JSON。它不操作滑块，不读取/转存验证票据，不调用成绩查询接口，也不向任何服务器上传数据。

目前已实现本地解析与导出原型，真实官网成功查询后的结果布局仍待核对。支持有明确表头的标准表格及可明确配对的 Element UI 表格；未知布局会停止，不能据合成页面测试宣称官网已经适配。

它用于桌面 Chrome 的本人侧接续验证，不是微信小程序内已上线的能力。小程序或网站的正式集成，需要另外确认来源支持的授权与返回方式。

## 本地使用

1. Chrome 打开 `chrome://extensions/`，启用“开发者模式”，点击“加载已解压的扩展程序”，选择本目录。
2. 在普通浏览器打开[中国马拉松大众成绩查询页](https://www.runchina.org.cn/#/data-score/public-score/list)。本人在官网填写身份信息、完成滑块并查询。
3. 成绩显示后，点击浏览器工具栏中的本扩展，选择“导出当前页成绩”。扩展不翻页；需要时在官网手动翻页，再导出。
4. 在本项目“我的 → 我的跑史 → 找回旧比赛”选择导出的 JSON，核对后保存。没有读取到的日期、项目、赛事类型、参赛形式和完赛状态需要本人补充；不会从赛事名称推测距离。
5. 页面无法读取时，可在扩展中展开“页面无法读取时”，导出结构报告。报告只包含表格形状、已识别表头、输入框类型计数及公开脚本域名等信息，不含成绩行、输入值、证件号、姓名、Cookie 或令牌。

导出仅限本人已查询的成绩。只找到当前页不表示已取齐历史跑史。站点出现安全拦截时工具停止，不自动重试。卸载扩展不会删除用户已主动导出的文件。

## 权限和处理范围

Manifest 只申请 `activeTab` 与 `scripting`；用户点击扩展时才在当前精确官网成绩路由执行一次读取。没有后台脚本、持久站点授权、网络请求、定时任务、身份存储或会话导出。成绩文件保存在用户本机，选择导入本项目后才会按现有私人跑史流程处理。

成绩解析采用表头白名单，跳过姓名、证件等列；不保存整页 HTML，不读取表单值、隐藏数据或网络响应。结构报告中的脚本域名只能帮助判断使用了哪类公开服务，不能证明验证码供应商或具体校验协议。
