# 跑量看板视觉重设

双端将时间范围收成日／周／月／年／累计分段控件，日期独立成轻工具条；莓红用于选择和入口，深绿渐变承载总跑量，暖白底配白色卡片。训练组改为双列网格，默认 4 个，支持展开／收起；成员榜用一个选择器替代横滑大按钮，搜索和“我的本期”独立成行。

选择器始终提交真实组号，含全员、未分组和已删除组的 404 回退。选中第 5 个及之后的组，再折叠卡片不会改变筛选，也不会额外请求；成员页返回保留原周期、日期与组别。长组名显示两行，大里程适当缩小字号；汇总小栏超万使用万／亿单位，总里程和组里程保留完整数值。仅改展示派生和组件 UI，API、计入规则、PK 计算与权限未调整。

本地验证（合成传输与临时浏览器，不写生产）：构建通过；旧 Web 27 项加新 UI 行为共 30 项通过（320／390／1440）；Mini 旧 14 项加新 picker／展开／账号重置共 15 项通过；5 场景 × 320／390 共 10 个源码镜像通过，含模拟原生默认 button 宽度；53 JS、38 JSON、38 WXSS 校验、34 WXML 与 38 WXSS 原生编译通过。摘要见 [report.json](../design/previews/club-mileage-visual-20261112/report.json)。
