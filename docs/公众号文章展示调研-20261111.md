# 小程序公众号文章展示调研

核实日期：2026-11-11。直接读取微信官方文档；搜索工具当日服务异常，以下技术结论依据官方页面正文。

## 可行结论

可以展示公众号文章的入口、摘要、来源，并由用户点击打开公众号原文。首选 `wx.openOfficialAccountArticle`，不要把“任意文章的原文跳转”与“web-view 内嵌整篇文章”混为一谈。

微信官方 [wx.openOfficialAccountArticle](https://developers.weixin.qq.com/miniprogram/dev/api/navigate/wx.openOfficialAccountArticle.html) 文档说明：基础库 3.4.8 起支持，通过小程序打开任意正常状态的公众号文章；不包括临时链接等异常状态文章，且必须有点击行为才能调用成功。该接口接受 `url`、`success`、`fail`、`complete`，不支持 Promise 风格调用。当前文档同时注明插件自基础库 3.15.1 起支持、鸿蒙微信支持。该 API 页面未要求小程序与目标公众号关联或为目标文章配置业务域名；这与 web-view 的约束不同。

推荐在资讯详情底部提供“阅读公众号原文”，在点击处理器中直接调用 API。不要在异步网络请求之后、页面自动加载时主动打开。后台先保存真实、正常可访问的永久文章 URL；小程序详情加载时即可取得 URL，因此点击不需要等待二次请求。

```js
function readOfficialArticle(url) {
  const copy = () => wx.setClipboardData({ data: url })
  if (typeof wx.openOfficialAccountArticle !== 'function' ||
      (wx.canIUse && !wx.canIUse('openOfficialAccountArticle'))) {
    copy()
    return
  }
  wx.openOfficialAccountArticle({ url, fail: copy })
}
```

失败时应允许用户复制链接并提示在微信中打开；旧基础库、原文删除、临时链接过期、网络错误等都不能表现为“已成功阅读”。API success 只代表接口调用结果，不等于阅读完成；返回 `cancel`、`confirm` 时也不能计为已读完。

## web-view 的边界

微信官方 [web-view](https://developers.weixin.qq.com/miniprogram/dev/component/web-view.html) 文档说明：基础库 1.6.4 起支持；个人类型小程序暂不支持；`src` 可打开关联公众号的文章，其他网页需要在小程序后台配置业务域名；网页内 iframe 的域名也需加入白名单。一个页面只能有一个 web-view，自动铺满页面并覆盖其他组件。因此不适合把任意公众号文章嵌入跑团卡片或资讯列表，也不能直接假定 `mp.weixin.qq.com` 的任意文章都能通过 web-view 打开。

对自有 H5 网站可按实际主体与业务域名配置另行接入 web-view，但本功能的公众号跳转不依赖这一做法。若未来要用 web-view 展示关联公众号文章，需在正式 AppID、实际关联关系和真机上验收。

## 产品与后台建议

- 公共“发现 / 资讯”统一汇聚业界新闻、人物档案、私兔档案与公开跑团文章；跑团详情提供该团的“资讯”入口与最近内容。
- 编辑器至少保存标题、摘要、封面（自有/获授权）、分类、正文或来源链接、来源名、作者、原文发布时间、内容权限/转载依据、发布范围、草稿/发布状态。
- 公众号转载默认保存人工编辑的简短摘要和原文链接，不自动抓取/镜像整篇正文或公众号图片。打开原文的技术能力不代表获得了全文和图片的转载授权。
- 发布前校验 `https` 和实际主机；公众号模式仅接受主机严格等于 `mp.weixin.qq.com` 的正常文章 URL，不接受冒充子串、用户名伪装或 `javascript:` 地址。保存原始 URL，避免破坏查询参数。
- 原生自有正文可直接阅读；公众号内容提供明确“阅读公众号原文”按钮；浏览器端正常外链打开。
- 跑团管理员可以在自己管理的跑团创建和发布团内资讯；平台资讯由平台后台发布。需要跨团公开推荐时由平台管理入口控制。

## 发布验收

本地可验证链接校验、点击调用、旧版本/失败复制降级。仍需在正式 AppID 真机分别验证：普通公众号文章、未关联公众号文章、失效/临时链接、iOS/Android（必要时鸿蒙）、用户取消、低基础库。不要把模拟器或接口 stub 的通过当作真实微信跳转验收。
