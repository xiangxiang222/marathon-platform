# 马拉松平台高明度界面设计

## 从参考图提炼的三种页面

| 页面类型 | 参考图里的视觉层次 | 马拉松平台的对应设计 |
| --- | --- | --- |
| 搜索入口 | 场景图承接标题，白色查询卡叠在画面上，全宽实色按钮收束输入流程 | 赛事首页用浅紫赛城插画作开场，直接接「找比赛」。模式、输入、结果的阅读顺序一致 |
| 服务入口 | 场景交代当前对象，白色卡集中最常用任务，浅灰区承接次要服务 | 赛事详情先交代比赛，再给报名、领物或查成绩。跑团先给当前关系和任务，再接可发现的跑团 |
| 个人身份 | 会员页用浅紫大色面、深色数字、白色的小卡和局部亮紫强调 | 个人中心以身份和完赛概览开场。成绩页把真实的完赛数据和最好成绩提到首屏，参赛记录用白卡承接 |

参考图中白卡与浅色底面之间的明暗差很小，分组主要靠圆角、留白和位置。欢迎弹层的整页暗罩是暂时出现的，平台的日常页面采用正常状态下的亮度。

## 配色、层级和尺寸

| 用途 | 颜色和尺寸 |
| --- | --- |
| 大面积页头 | 起始色 `#E8DEF9`，中段参考 `#DCD0F3`，向 `#F8F5FC` 或页面底色渐隐。个人身份区可多一层白色高光，赛历保持平整 |
| 页面底与卡面 | 底色 `#F7F6FA`，主卡 `#FFFFFF`。分组色 `#F3EEFC` 用于选中项、下阶段提示或补充信息 |
| 标题和数据 | 主字 `#22202A`，辅助字参考 `#62586F`。紫字 `#55388C` 用于文字入口、日期高亮与选中态 |
| 主操作 | `#7453B5` 到 `#55388C` 的低反差渐变配白字，常用主按钮高 48–50 px。其他操作用浅底或文字按钮 |
| 分组尺寸 | 常规左右边距 16 px，主要白卡圆角 20–24 px，区块间距 12–16 px。320 px 下压缩横向间距，主要操作触控区至少 44 px |
| 照片 | 实际赛事封面独立显示，文字所在区域用局部遮罩保证白字清晰。无封面使用浅紫跑道图形 |
| 底部导航 | 白底，未选项用深灰图标和文字，选中项用 `#55388C`。四个入口的位置与名称沿用现有产品 |

真实状态继续有自己的语义。报名截止、失败、个人最好成绩等用文字、图标或徽标明确标注，颜色只辅助识别。白字主按钮在渐变两端与底色的对比分别约为 5.8∶1 和 9.0∶1。浅紫页头的大字用深色，弱提示也保留足够对比。

## 页面布局

| 页面 | 首屏视线顺序 | 加载与空缺 |
| --- | --- | --- |
| 赛事首页 | 赛事标题和赛历入口 → 白色找比赛卡 → 快捷项和赛事列表。「按条件找赛」「搜赛事」各保留草稿 | 已提交条件与结果相对应，错误处重试同一查询 |
| 赛事详情 | 封面或浅紫跑道 → 白色参赛服务卡 → 赛事信息、参赛指南、成绩与资讯。主操作随比赛阶段变化 | 无官方入口时说明缺失；资讯可独立重试；按项目查看个人成绩，避免把其他项目的成绩带到当前项目 |
| 赛事资讯 | 浅紫搜索区 → 栏目入口 → 已选关键词与内容列表 → 文章。文章从标题继续到真实关联赛事 | 加载失败后保留已提交的关键词和栏目，没匹配内容时能清除条件 |
| 跑团 | 浅紫页头 → 我的跑团或当前可用服务 → 按城市、关键词发现跑团 | 访客可浏览公开跑团，加入与管理沿用登录和权限判断 |
| 赛历 | 浅紫页头和「回到今天」 → 白色月历 → 当天赛事。选中日有紫色圆形标记，日期格内显示赛事数量 | 翻月后展示新月份的加载状态；失败时就地重试，返回今天按北京时间定位 |
| 个人中心 | 浅紫身份区 → 白卡展示完赛概览、参赛计划、关注记录 → 设置与帮助 | 访客看到登录和公开入口；已登录后按实际数据呈现私人内容 |
| 我的成绩 | 浅紫成绩摘要 → 个人最好成绩 → 年份、项目筛选和逐场成绩记录 | 无成绩时引导记录第一场。已有数据时显示真实项目和成绩，长赛名允许换行 |

## 开发与验收

1. 在现有客户端回归脚本中添加具体行为和视觉断言。先让旧版页面加载成功，再记录实际失败原因，区分设计回归和夹具准备故障。
2. 按上述页面结构更新现有 Web 和小程序入口。从共享颜色角色入手，页面自身定义封面和身份区的版式。现有 API、路由及四个底部入口保留。
3. 在 320 px 与 390 px 检查首屏和长赛名、选择区、失败重试与重叠卡边缘；Web 同时检查桌面版。小程序源码镜像用于横向溢出和关键状态的对照，原生编译及包体检查另外运行。
4. 跑一遍赛事搜索、参赛计划、资讯检索、跑团创建与加入、个人记录和赛历翻月。完成后以同宽前后截图对照页头、白卡、按钮和文字的层次。
