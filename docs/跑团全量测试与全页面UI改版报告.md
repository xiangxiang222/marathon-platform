## 修复的问题

| 问题 | 修复与验证 |
| --- | --- |
| 管理手动计入一条原本未计入的跑步后，榜单里程仍为 0 | 首次计入时补齐本团计量。反复排除、恢复保持总量正确；规则变更后保留已确认的越野折算快照。原 10km 复现失败，修复后回归通过。 |
| 不存在的日期、非法月份/时间可以提交，部分报表窗口可能导致内部错误 | 校验实际公历日期、时分和自定义起止范围。非法输入返回 400，合法闰日正常通过。 |
| `toString` 等对象继承属性名可被误认为运动类型 | 使用自身属性白名单，只接受定义的运动类型；恶意类型不会入库。 |
| 日历和个别标签在窄屏缩成 8～11px | 取消过度缩放，农历、副标题、分组计数等可视文字不低于 12px；全页面浏览器检查通过。 |
| 统一行高后，跑步生涯日期过高，时间轴视觉不紧凑 | 给日期独立行高并保持单行；25 项跑者浏览器交互回归通过。 |
| 手机后台菜单允许底页滚动和焦点离开；关闭后焦点不能恢复 | 锁定滚动、约束 Tab，等待界面恢复后把焦点放回菜单按钮；覆盖 Escape 和关闭恢复。 |
| 建议保存重建列表后，侧栏关闭无法回到原条目 | 根据建议 ID 查找新条目并恢复焦点；补充提交禁用、完成后恢复和焦点断言。 |
| 后台队列只占半列、部分字段填值后看不出用途 | 队列跨满内容区，为相关字段补常驻关联标签，并优化手机列布局。 |
| 小程序窄屏导航、活动内容和分组表单存在溢出或尺寸不统一 | 修正导航宽度、安全区回退、搜索高度和窄屏表单列；全部 56 个源码镜像检查通过。 |

3 项后端缺陷均先在原实现上运行新增回归并失败，修复后通过，再执行完整服务端测试和批量业务复测。界面问题在各端专项检查中复测。

## UI 设计与全页面范围

参考[京东移动端](https://m.jd.com/)和[京东官网](https://www.jd.com/)的红白灰、主次操作、导航与卡片层级，结合赛事和跑团场景重新排版。主红为 `#e1251b`，浅红 `#fff2f0`，页面灰 `#f5f5f5`，主文字 `#262626`，辅助文字 `#737373`。使用原创图标、系统中文字体；统一圆角、标签、主次按钮、输入、禁用、选中和焦点状态，具体约定见[视觉规范](../design/视觉规范.md)。

- **Web**：首页、日历、雷达、资讯列表及正文、赛事详情、跑团列表和创建、公开介绍及邀请、身份核验及申诉、跑团全部导航和二级视图、发布训练、活动、报名、相册、赛事接龙、约跑、队内赛、运动、个人中心及设置、7 个跑者档案视图、跑史总览/导入/回顾、共创建议及详情、7 份协议、游客状态及未找到页。另补管理角色的总览、成员、服务、训练列表及详情。所有路由定义均纳入相应 Web 或后台检查；多步骤表单及动态状态由现有专项交互回归补足。
- **小程序**：逐一检查 `app.json` 全部 28 个注册路由，四个主入口调整信息顺序，所有次级页面和共享组件统一文字、控件、颜色、间距和表面，分享海报及导航资产同步配色。
- **后台**：登录和 13 个分区，赛事编辑器 9 个页签；覆盖平台管理员和跑团管理员的差异、手机抽屉、表格滚动、详情、空态、错误恢复、提交禁用和焦点。

## 如何复验

```sh
npm test
npm run test:clubs:full
npm run test:ui
npm run test:clubs
npm run test:history:client
npm run test:feedback
npm run test:legal
npm run test:client
npm run test:mini
npm run build
```

后台补充检查需要先在另一个终端运行 `npm run dev --prefix web -- --host 127.0.0.1 --port 5174`，然后 `npm run test:admin:ui`。浏览器脚本使用本机 Chrome，可用 `CHROME_PATH` 指定。全页面脚本自动启动独立 API/Vite 端口并清理自身资源。小程序镜像复验命令为 `node design/previews/mini-ui-source-audit.cjs`；各端报告齐备后运行 `node scripts/ui-review-gallery.cjs` 更新全端截图索引。

## 验证边界

Web 全页面检查使用真实本地接口、独立 SQLite 和合成资料，检查加载、可视字号、横向溢出、图片及浏览器脚本异常；198 项不表示穷尽所有输入组合和弹窗状态。后台专项浏览器检查使用模拟接口，持久化和业务权限由真实 HTTP 及服务端测试补足。小程序已通过微信原生离线编译和页面 VM 回归，56 张预览是浏览器源码镜像，尚未进行微信模拟器或实体 iOS/Android 设备验收。镜像记录中有 7 个视图的元素超出可视边缘，分别属于原生横向滚动区域或父容器裁剪的装饰图形；页面整体未横向溢出，不能把它表述为所有元素都位于屏幕内。

本轮没有执行生产部署、真实支付、微信消息发送、第三方自动同步或压力性能基准。中国马拉松官网滑块及外部赛事照片接入不属于本轮测试完成的能力。
