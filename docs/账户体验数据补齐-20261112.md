# 现有账户体验数据补齐

本次按用户要求，检查所有现有账户，按缺口补齐个人页面所需数据。已经有内容的部分保留；不修改账户昵称、密码、头像、真实运动、报名或成绩。

补齐目标：每人至少加入2个有效跑团、有4种赛事计划状态、2条完赛跑史、本月至少2条运动且最近7天有运动、至少2个团练报名。共享的体验跑团和赛事均以 `[体验]` 开头；体验完赛故事、虚拟路线和团练说明也明确用途。团练积分为0，模拟运动使用手填来源和虚拟跑模式，在已有跑团统计中固定排除，不冒充设备同步记录或真实比赛。

`scripts/seed-account-experiences.cjs` 默认只读预览，只有 `--apply` 才在单个事务中插入数据。每一条插入记录登记于 `account_experience_seed_registry`，记录主键、批次与完整行哈希。重复执行只补仍缺的内容，不重复灌入。本脚本不会自动向以后新注册的账户插入体验内容。

```sh
# 只读查看缺口和预计新增数量
node scripts/seed-account-experiences.cjs --database server/data/app.sqlite

# 备份后补齐全部现有账户
node scripts/seed-account-experiences.cjs --database server/data/app.sqlite --apply

# 可以只补指定账户
node scripts/seed-account-experiences.cjs --database server/data/app.sqlite --accounts 1,2 --apply

# 查看可清理内容，确认后才执行清理
node scripts/seed-account-experiences.cjs --database server/data/app.sqlite --cleanup
node scripts/seed-account-experiences.cjs --database server/data/app.sqlite --cleanup --apply

# 本机逐账户检查真实API（只向loopback发送认证，不输出凭据）
node scripts/verify-account-experiences.cjs --database server/data/app.sqlite --base-url http://127.0.0.1:3790/marathon/api
```

清理仅处理登记且未被修改的行；已经被编辑或产生后续业务关联的内容及其必要父记录保留。清理不会删除未登记的真实记录。

隔离验收使用独立临时数据库、媒体目录与真实HTTP服务，不加载 `.env`，不连接生产。4个账户覆盖空白账户及已有真实运动、私人跑史的账户，检查真实记录不变、重复执行无新增、个人数据隔离、跑团PK排除。Chromium在320/390宽度检查首页、我的、跑团、运动与跑史，共7项检查、5个视口截图（本提交仅保留匿名结果摘要）；见 `design/previews/account-experiences-20261112/report.json`。

生产修改前的一致性备份位于 `server/data/releases/editorial-accounts-20261112-03/`，正式执行前再次保存即时SQLite备份 `app-before-account-seed.sqlite`。2026-11-12已执行：检查205个账户，174个需补缺，共新增526行（3跑团、52成员关系、6体验赛事、34计划、10完赛成绩、26团练、340报名、10虚拟跑、42条统计排除关系、3跑团规则）。31个账户已有对应内容，未重复添加。

补齐后全部缺项计数为0。事务内逐条核对原有22,360行，全部保持不变；重复只读预览新增0行。生产真实认证API逐账户检查205/205通过，并验证170个新增团练报名账户的本人报名状态。报告见 [account-experiences-production-20261112.json](account-experiences-production-20261112.json)。补齐脚本7项单测、只读验收工具2项单测通过。
