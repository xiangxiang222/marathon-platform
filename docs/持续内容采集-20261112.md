# 当年成绩、A类赛事官兔与最近10天资讯

`npm run content:sync` 抓取公开来源，并把最近10个中国日期内、事实足够的新闻以完整整理稿发布。中国时间决定赛季年份及日期窗口；新闻不会因超过窗口而自动删除。每6小时更新一次，切年后自动读取新赛季。人数不足100时保留上一次完整榜单，并记录错误，避免把不完整名单显示为百强。

- 成绩：World Athletics 当年中国籍成年组全马赛季榜，男女各100人，每人一条，按赛季最佳排序。每周更新官方个人履历，按事实生成个人文章（`article.title/lead/body`），涵盖成长经历、全马进阶、当季比赛、大赛经历及其他项目记录，另以运动员编号匹配审核过的中文职业节点。PB、出生日期、成绩比赛另行核对，保留旧运动员详情链接。暂时取不到个人资料时保留此前完整章节并刷新文章；未查到的童年、入队与训练经历不编造。
- 官兔：中国田协当年A类马拉松及半马目录。定期查询当届赛事网站，再检查官网新闻与公告；已接入北京、广州、武汉、扬州的公开赛事CMS。默认列表以人为主体，支持 `raceId` 按关联赛事过滤，返回 `meta.raceFilters`。每人关联配速任务、PB、个人文章与赛事标签；“入选公示”和“已担任”分开，只有身份与实际任职均核实的经历进入已担任赛事。旧赛事详情链接继续有效。跨赛事同名者只有核实身份后才合并。赛事海报、合照不会作为个人头像，个人图片只在可对应本人时展示。公告中的证件尾号不进入数据。
- 新闻：央视网网页、视频公开搜索，以及已审核的新华网等补充来源。逐篇访问原文，只收录跑步马拉松，排除皮划艇等同名项目。正文独立整理赛况、成绩、赛道及城市信息，不复制原文段落。`digest` 标示事实整理，`sourceRefs` 保留多条资料来源。仅有视频标题/一句简介、事实不足或自动整理正文不足300字时进入 `recent-news.json` 待补池。按来源网址去重，合并重复报道，运营改题、改正文、改来源或下架后不会被自动覆盖。

运行数据保存在 `server/data/content/`，不会覆盖业务数据或本地编辑内容。采集文件原子替换；运行锁防止并发。单个来源失败不清空榜单、不阻断其他类别采集。来源失败及各类覆盖数量记于 `sync-status.json`，公开只读状态接口为 `/marathon/api/content/sync-status`。

阅读页面直接展示整理后的全文，不显示资料来源、外部原文按钮或采集说明；来源和身份核验依据留在后台数据供维护。网页与小程序都优先读个人 `article`，新闻署名为“跑圈编辑部”，跑团原创文章保留作者。详情页仍保留成绩、个人最好成绩与配速任务等结构化信息。

手动命令：

```sh
node scripts/content-sync.cjs --publish
node scripts/content-sync.cjs --only=news --publish
node scripts/content-sync.cjs --only=athletes
node scripts/content-sync.cjs --only=pacers
```

`--snapshot` 将成功采集的榜单与赛事数据同步到 `shared/` 作为部署初始数据。正常定时任务不加此选项。来源配置在 `shared/content-sources.json`。

本轮资料：男女各100名，200人均有PB及个人文章，文章合计102,943字符，中位数506；男女前20各篇461–1,232字符，中位数655。27人补充36段核实过的中文职业节点，其中7人有成长或职业转折故事。少数公开记录较少者按实际内容展示。9人有已核实名字对应的公开报道照片。部分选手中文姓名和照片仍待补证，保留世界田联登记名。A类目录221场，已查221场的目录详情，7个可用网站纳入跟踪；北京初步公示16组已拆分80位官兔，80人各有PB、配速履历和个人文章。武汉仅有公告、未取得可核实名单，暂不建立个人卡片。其他赛事不会用往届名单冒充当届。资讯由原有13条短链接升级为有实质正文的整理稿，剔除5条重复、非跑步或事实不足的内容；本轮发布12篇，正文约359–709字符，覆盖赛况成绩、参赛指南、路线调整及碳中和等主题。新闻正文与摘要不再含媒体名称、外链或“去原文查看”等措辞，事实证据仍保留在后台。后续数量以接口实时快照为准。
