# 系统权限与本地存储说明

版本：2026-11-01.1；更新日期：2026-11-01；生效日期：本版本正式发布之日

仅在您主动使用对应功能时申请或调用必要能力；原生能力是否需要系统授权，以微信及操作系统实际提示为准。

## 一、权限和原生能力

| 能力／接口场景 | 目的与时机 | 处理范围 | 拒绝／撤回影响 |
| --- | --- | --- | --- |
| 微信登录 wx.login | 您选择微信登录或绑定时签发临时凭证 | 用于登录核验；不自动获取通讯录、微信密码或手机号 | 可改用昵称密码；绑定、解绑按账号安全规则验证 |
| 文件选择 wx.chooseMessageFile | 您点击导入FIT／TCX时打开微信文件选择器 | 仅取得您选中的单场文件，上传本方临时解析，不读取全部聊天记录 | 本次导入不可用，仍可浏览或使用手填等功能；微信隐私声明另需维护 |
| 图片／视频选择 wx.chooseMedia等、头像选择 chooseAvatar | 您主动上传头像、证明、相册、建议截图或影像时 | 仅选中的文件；选择拍摄或相册由您决定，不遍历全部内容 | 对应上传不可用，文字和公开浏览不受影响 |
| 相机（原生选择器由您选择拍摄时） | 拍摄本次要上传的图像／视频 | 不后台持续拍摄、不申请麦克风进行独立录音；视频若含声音由所选媒体携带 | 可以改从已有媒体选择；具体授权在微信／系统设置管理 |
| 保存至相册 wx.saveImageToPhotosAlbum | 您点击保存成绩／活动海报时 | 把本次生成图片写入相册；不读取现有相册内容 | 不能自动保存，可按支持方式预览后另行保存 |
| 剪贴板写入 wx.setClipboardData／navigator.clipboard.writeText | 您点击复制链接、口令、名单或错误信息时 | 仅写入您发起复制的内容；不主动读取剪贴板 | 无法自动复制，可手动选择文字；复制诊断不应包含登录令牌 |
| 微信分享／系统分享、下载 | 您主动向朋友、群、朋友圈或本地保存时 | 分享公开团号链接或所选内容；您决定接收对象，不自动分享私人档案 | 不影响浏览；公开内容发出后他人可能保存 |
| 定位、通讯录、日历读取、步数／微信运动、系统手机号、蓝牙 | 当前没有启用这些读取能力 | 活动城市由您手填，签到为主动记录，不实时定位；不读取设备步数或生理传感器 | 不应为使用赛历要求开启这些权限 |

## 二、本地存储与会话

| 种类 | 保存内容与目的 | 位置与控制 |
| --- | --- | --- |
| 用户登录状态 | 登录令牌、昵称、头像地址，保持会话和展示本人资料 | 浏览器localStorage／小程序本地存储；退出登录清会话，清缓存可能需重新登录 |
| 管理员会话 | 后台登录会话，用于权限核验 | 浏览器sessionStorage；与普通用户账号分离，退出后失效 |
| 本人操作草稿 | 部分活动创建、共创建议草稿及暂存填写状态 | 相应客户端本地／内存；跨账号隔离，清缓存或页面关闭可能丢失，不保证跨设备同步 |
| 导航与交互状态 | 登录后的返回路径、待加入的公开团号、选择页签等 | 用于完成您发起的操作；不作为广告追踪标识 |
| 协议选择记录 | 明确接受的条款版本与服务端记录时间 | 本人账号相关记录；不把未勾选或旧版本自动标成已接受，也不代替敏感场景单独同意 |

## 三、怎样拒绝或撤回

在微信“设置—个人信息与权限／授权管理”及小程序右上角设置中，按当前版本提供的入口管理授权；手机相机、相册权限可在操作系统应用权限中管理。不同系统路径可能不同，以实际界面为准。

微信隐私授权弹窗由微信机制管理；本产品的隐私政策阅读、服务条款选择和微信原生隐私授权是不同事项，不能用一个按钮替代全部授权。撤回权限不自动删除已上传的记录；删除或注销可使用个人信息权利入口。
