# 后台全页面 UI 改版验收

验收日期：2026-11-05。范围为 Web 运营后台 `/marathon/admin` 的登录、13 个管理分区、赛事编辑器与两种后台角色。

## 改版结果

沿用京东风格的红白暖灰体系：主红 `#e1251b`、浅红 `#fff2f0`、页面暖灰 `#f5f5f5`，白色卡片统一 16px 圆角。后台采用系统中文字体和自然字距，说明文字最低 12px；标题、指标、表格正文、辅助信息各有明确层级。

导航按工作台、内容运营、跑团与跑者、平台管理、权益与合作分组；当前入口使用浅红底、红色图标和左侧标记。总览突出待处理事项和近期赛程；筛选表单使用常驻字段标签，状态采用文字标签。主动作使用红色按钮，次动作采用描边或文字，删除保留二次确认。

桌面保持紧凑的列表、并排编辑区和工单主从布局；手机使用抽屉导航、单列字段、可换行页签和至少 44px 的主要点击区域。样式限定在后台，不依赖全站颜色覆盖，也未引入 `!important`。

## 发现并修复的问题

| 问题 | 修复 |
| --- | --- |
| 手机导航打开后底页可继续滚动，键盘焦点可离开导航 | 打开时锁定底页滚动并约束 Tab；关闭和卸载时恢复状态 |
| 手机导航关闭后焦点未回到菜单按钮 | 等待 Vue 移除背景 `inert` 后再恢复焦点；增加回归断言 |
| 建议保存刷新列表后，关闭侧栏无法恢复到原列表行 | 等待侧栏移除后，按建议 ID 查找重建的行并恢复焦点 |
| 申请审核页的队列只占双列网格的一半 | 页签和当前队列跨满工作区，消除旁边无意义留白 |
| 多个物资、奖项、报名节点、账号和打回字段只靠占位文字说明 | 补充与输入框绑定的常驻标签，内容填入后仍可识别 |
| 导航与工单中存在 10/11px 字、低对比灰粉色及颜色不一致 | 后台字号最低 12px，统一中性灰与红色层级，工单状态保留语义色 |
| 跑团身份处理记录直接显示英文决定枚举 | 映射为中文处理结果，便于运营审查 |
| 手机上状态、编辑动作点击区域偏小 | 主要操作与页签扩为至少 44px，保持长内容换行 |

## 验证方式与结果

启动 Web 开发服务后执行：

```sh
npm run dev --prefix web -- --host 127.0.0.1 --port 5174
npm run test:admin:ui
npm run build
```

可通过 `MARATHON_PREVIEW_URL` 指定预览地址，通过 `CHROME_PATH` 指定 Chrome。原回归脚本保持不变，新增 `design/previews/admin-ui-full-audit.cjs` 对补充页面和 320px 尺寸进行检查。

- 原后台浏览器回归：62 项通过、48 张截图，覆盖 1440/1024/390 管理员及 1440/390 跑团管理员，包含登录、赛事保存/打回/通过、官网同步、入团审批、密码修改及权限界面断言。
- 补充全页面 UI 检查：138 项通过、132 张截图，覆盖 320/390/1024/1440；全部页面无文档横向溢出，检查 9 个赛事页签及三类工单的详情、空态、错误态。包括导航与建议侧栏的键盘焦点、滚动恢复、提交期间禁用、完成后可继续操作。
- 构建通过；后台修改文件的 `git diff --check` 通过。
- 两份浏览器报告均未记录页面异常或非预期控制台错误。模拟的 503 错误专门用于验证错误提示，不计为页面异常。

## 验收边界

以上浏览器检查的 API 读写全部由内存 fixture 响应，截图中的用户、跑团、工单均为虚构测试数据；它们证明界面、交互、响应式和角色展示符合预期。真实批量注册、跑团业务和数据持久化由独立后端验收负责，此报告不将模拟业务读写计为真实后端验收，也不代表中国马拉松官网或照片平台已完成接入。
