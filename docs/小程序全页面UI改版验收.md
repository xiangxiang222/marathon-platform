# 小程序全页面 UI 改版验收

日期：2026-11-05

## 验收范围

本次检查 `app.json` 注册的28条小程序页面，统一了主红 `#e1251b`、浅红 `#fff2f0`、暖灰背景 `#f5f5f5`、白色内容面与圆角；沿用现有原创图形，不使用京东标志或第三方品牌图。改版保留既有页面路由、业务字段、报名/管理流程、登录和隐私边界。

四个一级入口完成内容层级调整：赛历加入轻量介绍、搜索、快捷入口、赛事形式和筛选；跑团把已加入跑团、快速入口和发现/创建分成清楚的区域；运动突出本月里程、进度、跑步次数与记录操作；我的重排账户统计、运动摘要、赛程和跑者档案入口。跑团活动详情、报名、发布、赛事、跑史、档案及各种服务表单统一表面颜色、选中状态、字段字号和按钮尺寸。

共享样式补齐表单、空状态、说明文字、安全区和数字对齐；图标与分享海报采用统一主色。修正了跑步搜索输入在44px点击控件中的高度、双宽度窄屏导航溢出、活动详情导航横向溢出、底部筛选按钮换行、跑团搜索输入高度以及几类次级页表单字号和发布表单在窄屏的列布局。配置文件 `project.config.json`、`project.private.config.json` 未修改。

## 验证结果

- `npm run test:mini` 通过。微信开发者工具原生编译器 `wcc` 编译29个 WXML 文件，`wcsc` 编译31个 WXSS 文件；42个 JS、33个 JSON、51个模块引用和模块安全夹具检查通过。
- 九组小程序 VM 回归通过：跑团改版24项、跑团创建/账号隔离14项、成员/会费6项、活动打卡5个状态、详情恢复19项、跑者档案26项、跑史24项、反馈16项、法律/隐私24项。均使用内存请求或测试夹具，没有写入业务数据。
- `mini-ui-source-audit.cjs` 对28页的当前 WXML/WXSS 在320px和390px生成56张源码浏览器镜像。报告中每页均无页面级横向溢出，模板表达式错误数为0；7个视图仍记录横向滚动子项或被父容器裁剪的装饰元素超出可视边缘，这些不导致页面横向滚动；主入口与多步表单使用合成展示数据，无真实接口请求。
- 视觉镜像索引：[小程序源码镜像索引](../design/previews/mini-ui-20261105/index.html)，28页320/390宽度的镜像及每页 PNG 均在该目录；[全部页面320px缩略总览](../design/previews/mini-ui-20261105/contact-320.png)。
- `git diff --check` 通过。

## 边界

浏览器镜像由当前 WXML/WXSS 在 Chromium 中渲染，微信原生组件仅以浏览器元素替代；使用合成内容展示结构，不反映真实数据、机型字体、键盘、系统安全区或微信组件的最终尺寸。本环境未进行微信开发者工具模拟器真机预览或实体 iOS/Android 设备验收；最终上线前仍需使用微信开发者工具预览核对原生选择器、开关、按钮、底部安全区和不同系统字体。
