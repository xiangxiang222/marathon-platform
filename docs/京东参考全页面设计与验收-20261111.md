# 京东参考 · 全页面设计与验收

2026-11-11。本轮按用户最后确认的京东方向重新设计。参考用户提供的五张截图，并调研 [京东官方 App Store 页面](https://apps.apple.com/cn/app/id414245413) 和 Apple 返回的应用截图。红色品牌区、黑灰文字层级、白色内容卡与紧凑控件是视觉观察后的项目设计取舍，不宣称获得京东内部设计规范。

## 最新调整：原创小插画与内容重排

用户进一步要求“自己设计一些小的图片”。已用同一生成源绘制七类原创插画：日历、奖牌、双人伙伴、资讯纸张、跑鞋、跑者护照、成绩海报。资源提供可编辑SVG与本地透明PNG；主入口不使用通用摄影。插画常规48–58px，内容模块64–90px，标题与数据保持原生文字。

四入口重新编排：赛事为搜索、图形快捷入口、紧凑功能卡和真实赛事列表；跑团为单团/多团名片、伙伴小插画和搜索；运动为月跑量、真实分周图、目标与记录；我的为紧凑身份、周报、完赛成绩与三列工具台。运动员与私兔入口也使用奖牌/跑鞋小图，避免通用照片错误对应真人。

赛事日期采用清晰的月份条与日期数字。320px的筛选入口固定在右侧；压缩导览模块高度，尽早展示实际赛事。清理我的全部分支与页脚的微小字号，阅读文字至少12px。退出仍在设置，海报跟随个人成绩。

## 可复现检查与范围

- `npm test`：服务端全部测试，使用隔离数据。
- `npm run test:client`：客户端行为回归，自动准备本地预览服务。
- `npm run test:mini`：微信WCC/WCSC离线编译及模块/样式引用检查。
- `npm run build`：Web生产构建。
- `npm run test:content`：资讯权限、人物数据、两端浏览/发布与原文打开契约。
- `UI_AUDIT_OUT=design/previews/jd-visual-v3-20261111/web UI_AUDIT_REPORT=design/previews/jd-visual-v3-20261111/web-report.json UI_AUDIT_CAPTURE_ALL=1 node scripts/ui-full-audit.cjs`：生成全页面Web截图与报告。
- `UI_AUDIT_OUT=design/previews/jd-visual-v3-20261111/mini UI_AUDIT_REPORT=design/previews/jd-visual-v3-20261111/mini-report.json node design/previews/mini-ui-source-audit.cjs`：生成小程序全部源码镜像。
