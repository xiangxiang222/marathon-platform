# 京东参考 · 全页面设计与验收

2026-11-11。本轮按用户最后确认的京东方向重新设计。参考用户提供的五张截图，并调研 [京东官方 App Store 页面](https://apps.apple.com/cn/app/id414245413) 和 Apple 返回的应用截图。红色品牌区、黑灰文字层级、白色内容卡与紧凑控件是视觉观察后的项目设计取舍，不宣称获得京东内部设计规范。

## 最新调整：原创小插画与内容重排

用户进一步要求“自己设计一些小的图片”。已用同一生成源绘制七类原创插画：日历、奖牌、双人伙伴、资讯纸张、跑鞋、跑者护照、成绩海报。资源提供可编辑SVG与本地透明PNG；主入口不使用通用摄影。插画常规48–58px，内容模块64–90px，标题与数据保持原生文字。

四入口重新编排：赛事为搜索、图形快捷入口、紧凑功能卡和真实赛事列表；跑团为单团/多团名片、伙伴小插画和搜索；运动为月跑量、真实分周图、目标与记录；我的为紧凑身份、周报、完赛成绩与三列工具台。运动员与私兔入口也使用奖牌/跑鞋小图，避免通用照片错误对应真人。

赛事日期采用清晰的月份条与日期数字。320px的筛选入口固定在右侧；压缩导览模块高度，尽早展示实际赛事。清理我的全部分支与页脚的微小字号，阅读文字至少12px。退出仍在设置，海报跟随个人成绩。

## 已完成的改版

四个主入口统一红色品牌顶部、白色搜索或首张卡片、浅灰正文背景。标题字号24px，说明12px；状态栏与胶囊继续读取微信真实系统尺寸。底栏选中和小图标统一品牌红 `#FF1838`。

二级页面按同一规范梳理：正文和输入14px、列表标题16px、分区18px；辅助信息至少12px；系统黑体、自然字距、400/500/600字重；白卡12px圆角、控件10px圆角。跑量数据36–40px，训练组白灰底，红色表达选中和进度。折叠使用整行文字和箭头，不重复套边框按钮。

赛事分享改为一个展开区域、选择跑团、一个主要操作，保留原有复制内容和原生微信分享能力。退出登录仍在我的右上角设置里，制作海报跟随完赛/PB信息。我的六个功能卡缩短说明，避免窄屏单字孤行。

覆盖范围包括赛事首页、日历、雷达、赛事详情、跑团发现/创建/介绍/身份/举报、跑团五个页签及管理服务、跑量和训练组、成员档案、团练发布/报名/相册、约跑/队内赛/成绩统计、运动记录/目标/编辑、我的各页签/设置、跑者七个子页、跑史导入与核对、资讯/人物详情/发布、反馈/奖励/权利申请、协议与隐私，以及后台14个工作区和内容发布。海报工作台控件统一，用户导出的海报作品保留模板设计。

规范入口：[控件与页面规范](../design/控件与页面规范.md)。旧小象与多色卡片文档已标记为历史方案，避免后续实现再次引用冲突规范。
