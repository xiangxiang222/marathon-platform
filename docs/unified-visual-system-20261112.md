# 全站视觉统一（2026-11-12）

本规范以已认可的赛事页为基准，取代此前彩色、暖白与绿色页面方案；旧验收文档仅保留为历史记录。

## 统一规范

- 品牌红 `#ff1838`，选中浅红 `#fff0f2`；主文字 `#1a1a1a`，辅助文字 `#777777`，分割线 `#eeeeee`，白卡，页面底 `#f5f5f5`。
- 四个主导航页面使用实红页头与白色 24px 标题；业务详情使用白色标题栏。主导航采用短红下划线，次级筛选为等宽浅灰/浅红控件。
- 页面标题 24px、区块标题 18px、列表标题 15px、正文/控件 14px、辅助文字至少 12px；长文 16px/1.9。字重 400/500/600，中文不加字距，窄屏不缩小字体。
- 页面边距/卡片内距 16px，区块间距 24px，卡片间距 12px；卡片圆角 12px、输入和操作控件 8px。主操作至少 44px，搜索按钮紧凑，次操作保持可点击区域。
- 移除绿色数据主题、糖果色首字头像、装饰性大插画、渐变背景墙与嵌套卡片。真实照片与用户生成的海报作品保留原色。
- 保留现有角色权限、账户隔离、表单字段、状态和业务接口；视觉调整不更改线上数据。

## 页面责任清单

- 基础与赛事：全局样式、页头/分页/导航、赛事列表/详情、日历、拿奖雷达。
- 内容与后台：资讯各栏目、男女运动员列表、按人展示的官兔及赛事筛选、文章/人物详情、后台所有导航分组和编辑面板。
- 跑团：目录、详情全部标签、团友资料、训练组、跑量、合作、动态。
- 活动与服务：团练发布/详情/报名、相册、接龙、约跑、内部赛事、公开介绍、创建、身份反馈/申诉、团内资讯编辑。
- 个人：运动、我的全部标签、跑者档案全部标签、跑史、导入/核对、成就海报入口、反馈、隐私权利、法律文本与空态/未登录态。

以 32 个注册小程序页面与 Web 路由为基准，另检查空态、错误态、表单、弹层、角色权限和 320/390px 窄屏。源码镜像仅用于布局检查；原生 WCC/WCSC 用于编译检查，两者都不等同于微信真机验收或正式发布。
