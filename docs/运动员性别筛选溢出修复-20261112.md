# 运动员性别筛选溢出修复

原布局把男子、女子按钮与赛季说明放在同一行。小程序原生按钮的默认宽度使两个按钮占满一行，后面的文字继续向右延伸，撑大页面。

赛季说明现独立显示在筛选上方，男子和女子按钮各占可用宽度的一半。小程序显式设置按钮的宽度和 flex 伸缩，避免默认宽度干扰。网页同步调整，保留性别切换与选中状态。

- 真实临时 API / Chromium：320/390 各切换男子、女子、男子，6 个视图通过，按钮等宽且点击区域至少 44px，无横向溢出。
- 小程序源码镜像：男子、女子、加载失败三种状态 × 两种宽度，6 个视图通过；注入原生按钮默认宽度后同样通过。
