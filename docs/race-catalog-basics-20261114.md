# 首页赛事档案首版

首页精选区与赛事提醒之间增加北京、上海、厦门三场的基本列表。显示名称、城市、简称、一句话简介，以及分开的世界田联标牌与中国田协认证，认证均注明2026年。未完成的详情、年度资料、报名回链与动画不提供入口。

Web与小程序均匿名读取 `GET /marathon/api/race-catalog`；加载失败只影响本模块，可点击重试，原有赛事列表继续可用。共享数据为 `shared/race-catalog.json`，包括每项认证的证据链接；不能将世界田联等级与田协A类混成一套高低排序。

2026年国际标牌来自[世界田联标牌路跑日历](https://worldathletics.org/competitions/world-athletics-label-road-races/calendar-results)：北京金标，上海与厦门白金标。国内类别使用仓库 `shared/a-class-races.json` 的2026年官方目录快照，三场均为A类，具体赛事链接保留在各条 `sources` 中。

此前小程序已更新而线上服务未更新，导致接口404。已在服务端补充路由和三场数据，公共域名实际请求已返回200。此次合入将API、数据与两个首页放在同一提交；新API回归覆盖游客访问、三场名单和带年份的独立认证来源。

验证：服务端测试、Web构建、小程序原生编译及包体积检查；Web在320/390/1440宽度检查三场显示、窄屏排版、错误重试和搜索时隐藏。小程序编译和本地逻辑检查不代替真机验收。
