# 跑团目录视觉设计与验收

双端目录改为暖白背景与白色卡片，墨色正文、灰绿次字、莓红小面积强调。卡片使用16px圆角、16px页面边距，列表头像以低饱和绿、麦色、灰紫和浅莓区分，细分隔线从文字列开始，避免整页只有灰白横线。

顶部取消大红色块，改为浅色标题区与三笔莓红标记。我的跑团保留纵向默认4条、全量独立搜索、展开收起，增加成员/角色胶囊；团练和赛事使用30px视觉高度的边框次按钮，触控范围仍为44×44px。发现区以分段切换、完整一行搜索、轻量城市行形成操作层次；结果使用文字和细箭头进入，审核中另有状态标记。底部只保留一个创建入口，以轻微莓色过渡和独立加号标记区分。

网页script setup与小程序clubs.js经SHA-256比较完全未改；所有现有路由、API、权限、异步账号隔离和建团表单保留。城市输入保留可访问名“筛选活动城市”，网页新增“应用城市筛选”按钮复用原search方法，有值时保留“不限”清除。

小程序page-header新增可选tone属性，默认brand保持既有红色；只有clubs指定light。原状态栏高度、胶囊预留和resize计算保留，clubs.json改为暖白背景与黑色导航文字，onShow未覆盖该配置。源码镜像工具同步读取tone，默认brand。

验证全部通过：网页真实本地API与浏览器9项/12视图；小程序Page VM行为5项；源码镜像8状态×320/390共16视图；另做默认brand头部2视图；网页构建通过。默认4、展开10、全量名称/城市/团号搜索、切号清空、旧账号晚响应、口令跳转和从底部实际建团均保留。双端320px长名称及18px主文字/14px次文字场景已实际查看，无横向溢出。

```sh
node scripts/club-directory-v5-live.cjs

npm run build
```
