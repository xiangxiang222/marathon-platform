# 资讯、反馈与协议页面：统一控件与字体验收

本轮按京东参考方向统一页面内部的文字、列表、卡片和控件，不把商城的营销宣传海报直接搬进文章阅读或表单。

## 参考与规范

- 官方参考：[京东中国 App Store 页面](https://apps.apple.com/cn/app/id414245413)。2026-11-11 读取 Apple 官方 iTunes Search API，返回主体 Beijing Jingdong Century Trading Co., Ltd.、版本 16.1.81、版本更新时间 2026-10-31。
- 直接查看官方第 1 张「京东 11.11」、第 2 张购物助手、第 4 张「AI 问答卡」截图。营销背景使用鲜明红色，产品内部以白色导航、浅灰筛选控件、固定图文行、黑色标题、灰色辅助信息和红色关键数据为主。字号和圆角的判断属于视觉观察，不宣称是京东公开设计 token。
- 本项目采用统一品牌红 `#FF1838`，正文页白色导航；背景 `#F5F5F5`、白卡；主要文字 `#1A1A1A`、辅助文字 `#777`。局部样式引用全局语义 token。
- 中文系统字体、正常字距。辅助信息至少 12px，正文和表单 14px，列表标题 16px，分节标题 18px，页面和文章标题 24px。正文 400、操作 500、标题 600。
- 卡片圆角 12px，输入和按钮圆角 10px。核心点击目标至少 44×44px，错误、空状态和无权限状态沿用同一体系。

## 页面与分支

| 页面 | 验收分支 |
| --- | --- |
| 资讯中心 | 精选、运动员男子/女子、私兔、无结果、接口不可用、重新加载恢复 |
| 资讯与人物详情 | 普通文章、运动员、私兔、分钟精度 PB、来源入口、接口不可用 |
| 跑团内容发布 | 初始表单、已有草稿、Markdown 预览、原文推荐、空文章库、保存中、接口错误、非管理员、游客 |
| 共创建议 | 公开列表、我的建议、游客、筛选、无结果、加载中、接口错误 |
| 建议提交 | 文字草稿、表单分类、截图入口、表单错误、关闭与恢复 |
| 建议详情 | 公开建议、本人待审核、回复和时间线、他人已采纳、本人领取奖励、收件表单、已发货、确认弹层 |
| 协议中心 | 隐私、服务条款、收集清单、共享清单、权限、未成年人、个人权利共七份完整文件；离线内置版本；不存在的文件 |
| 权利申请 | 游客登录入口、本人填写、更正事项、历史申请与回复、读取失败、提交和会话切换 |
| 小程序隐私授权 | 普通阅读、待授权、隐私指引打不开、主动同意、拒绝及返回 |

## 验证方式

1. `node scripts/content-mini-regression.cjs`：资讯 17 项 VM 业务检查。
2. `node design/previews/feedback-mini-regression.cjs`：反馈 16 项 VM 业务检查。
3. `node design/previews/mini-legal-regression.cjs`：协议与隐私 24 项检查。
4. `node scripts/content-live-acceptance.cjs`：真实本地 HTTP、独立临时数据库，资讯发布/筛选/来源/上下架/404 重试，7 项检查和 40 张截图。
5. `node design/previews/feedback-live-acceptance.cjs`：真实本地 HTTP，提交、审核、投票、奖励、本人/他人、撤回，12 项检查和 16 张截图。
6. `node design/previews/legal-live-acceptance.cjs`：真实本地 HTTP，七份文档、离线内置回退、版本同意、私密权利申请、后台回复及会话防串数据。
7. `scripts/reading-pages-mini-fixture.cjs`：执行当前小程序 Page 方法，使用合成 HTTP 数据；45 场景 × 320/390，共 90 张 WXML/WXSS 源码镜像，逐场景检查可见文字 ≥12px、正常字距、控件 ≥44px、页面不横溢出、错误状态和首屏内容。
8. `node scripts/reading-pages-web-audit.cjs`：当前 Vue 页面和合成 HTTP 夹具，覆盖列表、编辑、预览、错误、游客/非管理员、反馈表单/奖励、七份协议和权利申请，检查字体、字距、控件和横向尺寸。

小程序镜像命令：

```sh
MINI_AUDIT_FIXTURE=scripts/reading-pages-mini-fixture.cjs \
MINI_AUDIT_ROUTES=pages/news/news,pages/news/detail,pages/news/editor,pages/feedback/feedback,pages/legal/legal,pages/privacy/privacy \
UI_AUDIT_OUT=design/previews/reading-pages-jd-20261111 \
UI_EXPECTED_ACCENT='#ff1838' \
node design/previews/mini-ui-source-audit.cjs
```

小程序源码镜像只用于当前 WXML/WXSS 的浏览器布局检查，不是微信开发者工具或真机截图。原生控件、键盘、授权、公众号打开和安全区仍需在微信环境验证。本轮未发布到线上，新资讯接口在生产环境尚需与后端一起更新；界面不使用虚构数据掩盖缺失接口。

- 小程序：45 场景、90 张源码镜像，全部通过；报告 `design/previews/reading-pages-jd-20261111/report.json`。
- 网页：36 场景、72 张完整页面截图，全部通过；报告 `design/previews/reading-pages-web-jd-20261111/report.json`。
- 构建、微信 WCC/WCSC 原生编译、资讯 17 / 反馈 16 / 协议隐私 24 项 VM 回归通过。

- 发布表单预览的浏览器默认 `small` 字号、反馈短分类按钮及窄屏的收起/刷新按钮均在审计中发现并修复。
