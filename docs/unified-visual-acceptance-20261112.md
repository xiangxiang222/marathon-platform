# 全站统一视觉验收 · 2026-11-12

以[统一规范](unified-visual-system-20261112.md)为基准，合并基础/资讯/后台、个人/运动、活动/服务、跑团四组改版。四个主入口使用同一实红页头和 24px 白标题；其余界面按内容需要组织，统一字体、灰白表面、红色操作和边距。

验收逐页包含全部 32 个注册小程序页面、71 个 Web 页面/角色/展开场景及后台导航与编辑面板。移除绿色 UI 主题、暖白主题、糖果色首字头像和装饰插画；赛事页已认可的工具插画保留，实际照片及海报输出保留原色。

## 目视复核后修正

- 资讯编辑的四个按钮改为两列，窄屏不再挤成两行文字。
- 跑史返回/关闭、上传关闭、相册入口与接龙删除保留44px点按区域。
- Runner上传与海报预览使用半透明遮罩；修正上传面板关闭按钮与拖动条尺寸。
- 人物详情兼容缺少个人成绩数组的记录，不影响其余履历展示。
- 新增背景色、字重与字体尺寸检查，防止后续局部样式再次偏离。
