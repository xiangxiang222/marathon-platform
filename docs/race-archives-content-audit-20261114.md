# 三场档案资料补充与显示方式

本轮围绕现有10届整理可核验事实：北京2023—2026，上海与厦门2024—2026。年度资料来源共66条（北京23、上海15、厦门28），之外保留基本认证来源。不能将“查过全部栏目”称为“所有资料已取得”。

## 新增与纠正

- 北京：四届检录、分段关门、存取包、补给、厕所与医疗；2025领物时间地点、本人核验与物资数量；2026抽签公布日期。纠正2023—2025终点关门为13:45，2026为13:30。
- 上海：2024—2025报名日程、路线、领物、交通、分枪、物资和四类冠军；2026报名、抽签、缴费与扩容。赛后新闻用计划规模概述出发人数时，不将其写成芯片统计实际起跑人数。
- 厦门：三届领物、接驳、发枪、关门、存包、补给、医疗和物资清单；三届中国籍男女冠军。2026预报名206910、公布“其余选手”中签率10.73%，保留2025同样受限口径的11.8%，不与全体报名者概率混同。

## 阅读与媒体

按用户要求移除“本栏资料来源”、原文/复制链接等操作。事实自行归纳，保留编辑核验记录与各届sourceIds。详情使用城市地标页头、起终点与编号道路顺序、分类物资清单；信息没有证据时集中在折叠收录说明中。历年中签表只保留至少一届有值的列。

版权调研依据为[中国政府网《著作权法》](https://www.gov.cn/guoqing/2021-10/29/content_5647633.htm)：第五条排除单纯事实消息；第十条规定复制和信息网络传播等权利；第二十四条的合理使用有条件并涉及署名。公开可见、非收费、标明出处都不能单独证明图片可自由转载。此为实施依据的初步核查，不构成对全部素材零风险的结论。

当前原始路线图、摄影与物品图片未取得明确许可，内部记录保留，公开API不下发媒体URL，旧缓存路径返回404。自有、明确许可及公有领域媒体才允许公开；许可媒体须保留权利人、作品名、许可证明与所需署名。不会为了视觉效果画出看似真实的奖牌或地理轨迹。

验证包含服务端322项、小程序5项回归、Web21项/78视图、WCC/WCSC原生编译、Web构建、包体积和320/390源码镜像。部署后再核实三场在线详情、切年、参赛指南、无来源按钮与媒体过滤。小程序源码与编译检查不等同真机发布。
