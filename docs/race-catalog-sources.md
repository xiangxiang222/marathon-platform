# 赛事档案设计样本：内容与证据说明

核验日期：2026-11-13。数据文件：[shared/race-catalog.json](../shared/race-catalog.json)。

首期范围为北京马拉松、上海马拉松、厦门马拉松三场，仅在首页展示名称、城市、简称、一句话简介与年度认证。共享数据只保留这三场基本资料；下方北马历史研究作为后续采编笔记保留，不属于当前页面或接口已交付内容。上海、厦门详细年度资料待补。展示顺序是编辑安排，不代表全国排名。全国30场的扩展设想属于后续规划，不是本轮交付范围。

## 目录证据

### 世界田联标牌

直接读取[世界田联2026年标牌路跑日历](https://worldathletics.org/competitions/world-athletics-label-road-races/calendar-results) HTML 中公开的 `CalendarEvent` 数据，保留原始 `competitionSubgroup`、日历事件ID、英文名和日期作为每场 `sources[].evidence`。首期三场均匹配到对应的全程马拉松事件。

| 2026年国际标牌 | 首期赛事 |
| --- | --- |
| Platinum / 白金标 | 上海、厦门 |
| Gold / 金标 | 北京 |

国际标牌需带所属年份，不能成为赛事永久属性。

### 中国田协认证

使用仓库现有 [shared/a-class-races.json](../shared/a-class-races.json)，这是2026-11-12采集的中国马拉松官方目录快照，源为中国田协[公开赛事查询接口](https://api-changzheng.chinaath.com/changzheng-content-center-api/api/homePage/official/searchCompetitionMls)。北京、上海、厦门三场在快照中 `grade` 均为 `A`，每场保留对应[中国马拉松赛事详情](https://www.runchina.org.cn/)深链接和 `officialId`。

三场均按全程马拉松全称匹配，避免把北京半马、厦门海沧半马等当作对应全马。目录快照的 `A` 不能在没有当年规程或田协认证依据时擅自细化为 `A1`。

国际标牌和国内田协认证是两个并行字段。后续筛选应分别处理“白金标”和“A类”；首版仅分开展示，不提供筛选。

### 上海、厦门的内容状态

[上海马拉松官网](https://www.shang-ma.com/)与[厦门马拉松官网](https://www.xmim.org/)作为后续采编入口保留。本轮未完成两场各年度竞赛规程、精确路线、报名和完赛数据、完整物品清单及实物图片的逐项核验。详情应明确显示“年度资料待补”，不套用北京资料，也不以概括文案或图片占位冒充完整档案。

2026世界田联日历可支持上海12月6日、厦门1月11日的目录日期；这些日历日期不能替代各届竞赛规程中的起跑时间、规模、项目和路线证据。

### 最新路线与首期展示边界

[官网比赛路线页](https://www.beijing-marathon.com/subject.html?detailId=7992140408205034&topicId=7793644601957146)最后更新于2026-09-28，提供[官方高清路线图](https://pub.mararun.com/cms/pic/BJCN/28c34fc407162d6aafa06ce2a015384c.jpg)。图片证据可用作“查看官方路线图”；使用或转载前应确认素材授权与展示方式。

2025、2026规程公开了逐条道路序列，包含西长安街、复兴路、玲珑路、蓝靛厂、学院路、国家速滑馆区域与奥林匹克区域。两份规程所列道路序列一致。这仅支持“规程道路序列一致”，不支持断言实测路线、高程、补给点或交通组织完全不变。

路线动画已按用户决定暂缓，不属于首期设计原型或实现范围。当前没有经过校核的官方GPX/GeoJSON、逐点距离与高程，也没有分年份地图资产归档。首期使用静态官方路线入口与文字分析，并遵守以下边界：

- 未拿到路线高程前不展示累计爬升、坡度曲线、难度分或“PB指数”；后续路线分析仅能基于已核验道路序列作编辑定性解读。
- 2026官方图片不回填成2023、2024历史路线图。旧届精确路线差异仍待采集。
- 后续若恢复路线动画，应另行取得与届次、项目和版本绑定的可靠轨迹；不得把官方路线图描线或AI生成曲线当作精确轨迹。

### 参赛包、完赛包、服装与奖牌

四届竞赛规程可支持基础物品清单，如参赛服、存衣包、号码布、计时芯片，以及按规程完赛后可领取奖牌与完赛物品。但规程没有给出完整实物明细，也不能证明衣服颜色、品牌、版型、尺码、男女款或奖牌尺寸。

数据中 `gear.racePack` 仅收录当届规程列明物品；`gear.finisherPack` 对未逐项列明的部分保留文字说明；`gear.images=[]`。不要用其他年份或生成图片伪装成北马真实物资。上线素材应逐项记录年份、品类、正反面、图片权利人、来源公告与使用权限。

## 内容状态与采集约定

本文件空字符串表示“尚未核验”，不等于数值0。`directory_verified` 只说明目录信息已核验；`partial_archive_verified` 说明部分历史档案有证据；不自动意味着全档案完整。

后续应把每一个统计值升级为独立对象，至少包含 `value`、`unit`、`scope`、`distance`、`gender`、`status`、`sourceId`、`publishedAt`、`verifiedAt` 与 `version`。尤其要拆分：

- 预报名、有效报名、进入抽签池、中签、递补、直通、公益／赞助名额和缴费成功人数。
- 赛前计划规模、领物人数、实际起跑人数、关门内完赛人数，以及不同定义的完赛率。
- 枪时冠军、净计时排名、中国籍冠军、赛会纪录、国内纪录和大众成绩分布。

只有同年、同项目、同组别、同轮抽签且分子分母均有证据时，才计算抽签中签率。总规模除以预报名总人数只能在证据允许时标为估算竞争比，不能标成实际中签率。
