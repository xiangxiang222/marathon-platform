# 三场年度赛事档案

本轮延续首批北京、上海、厦门三场，补充可实际打开的档案目录和年度详情。动画仍按此前决定暂缓。

## 入口与阅读

- 首页的三张卡片可打开各自档案；“全部档案”进入独立目录，支持名称、城市、简称搜索，世界田联标牌与田协认证分别筛选。
- 单届赛事页面在匹配对应全程马拉松时提供“报名前，先了解这场比赛”。档案列出平台已收录的对应单届赛事，可返回报名信息；半马、越野和线上赛不混入同名全马。
- 详情按概览、赛道、报名中签、参赛完赛、装备收藏、赛事故事六栏阅读。切换年份后，该届日期、路线、报名、成绩和物品一起切换；每栏有原文来源。默认打开最近资料较完整的一届；用户仍可选择只收录了日历日期的新届，不将旧届规则自动复制过去。
- 历年中签表区分预报名、有效报名、抽签池、抽签名额、直通名额和官方公布的中签率。未知字段显示未收录，既不记零，也不以总规模除报名人数冒充中签率。
- 计划规模与实际出发、完赛分开；参赛包与完赛包分别记录发放物品。服装、奖牌只使用对应年份的真实资料。图片加载失败仍能阅读正文、清单和原文。

## 数据与维护

基本身份和年度认证保留在 `shared/race-catalog.json`；按场年度资料在 `shared/race-archives/{beijing,shanghai,xiamen}.json`。各文件独立维护来源ID；每届保留日期、路线、报名、参赛完赛、成绩、物品及说明。新增年份不得覆盖旧届资料；有更正时同时更新来源及核查日期。

接口均可游客访问：`GET /api/race-catalog?q=&wa=&caa=` 为轻量目录，`GET /api/race-catalog/:id` 返回档案、可选年份及实际关联单届赛事。档案ID由固定三场映射，不用用户输入拼接读取路径。该功能不新增个人信息采集、不修改参赛计划或成绩。

路线分析属于编辑基于公开道路与地标资料的阅读建议，不生成没有可靠轨迹支持的海拔、坡度、PB指数或导航精度。图片保留原文出处；没有可靠本届图片时不借用其他年份或生成图片。

当前维护通过版本化JSON发布，尚未新增后台可视化档案编辑器。动画、扩展30场、社区评分和用户投稿属于后续工作。

## 验证与发布

服务端测试覆盖独立认证交集筛选、别名搜索、未知档案404、跨年证据引用、单届与档案匹配、半马及线上赛事排除。双端检查覆盖年度切换、空态/错误重试、资料来源、报名回链及图片降级；窄屏表格在自身容器滚动。

本轮使用隔离工作树，API、三场资料和两个客户端一起提交。服务端320项测试、小程序5项行为回归、Web 21项检查（63个视图）、Web构建、小程序原生编译与包体积检查通过后合入；部署完成再访问公共接口与Web静态资源。微信小程序需开发者工具重新编译或发布客户端更新，源码检查不等同于真机发布。
