# 个人信息处理事实核对

核对日期：2026 年 11 月 1 日。核对对象为本仓库当日工作区中的服务端、网页和微信小程序业务代码，包含跑团身份保护、运动文件导入、私人跑史与本地图片识别、法务模块改动。本文件是协议编写和上线配置核验的事实底稿，不等同于部署审计、法律意见或已完成的合规承诺。后续新增自助注销执行、权限或 SDK 等功能应同步复核本表。

本次未读取 `.env`、线上数据库、用户上传文件或其他生产秘密；未核验微信后台隐私声明、线上网络流量、云服务合同及实际日志配置。

## 一、协议需要优先说明的事实

1. 平台有网页和微信小程序。网页账户支持昵称、密码；微信登录通过本方服务端向微信交换登录凭证，代码只持久保存 `openid`，未发现保存 `unionid`、`session_key`。不应将预留字段或尚未开通的接口写成正在使用的服务。
2. FIT / TCX 文件由用户主动上传本方服务器并在内存中的独立 Worker 解析。原文件可能携带 GPS、心率等内容，因此“完全不接收原文件或 GPS / 心率”不准确；当前代码只持久保存运动摘要，不保存原文件、GPS 轨迹点和心率样本。
3. 跑团功能具有成员间展示、团长导出、管理人员处理等可见范围。跑量截图可被与作者同处任一跑团的成员读取；不能把所有运动材料统称“仅本人可见”。个人赛事报名截图、个人成绩凭证和跑者收藏有本人鉴权。
4. 性别、出生年月、省份、目标成绩由用户主动填写。出生信息为 `YYYY-MM`，不是完整出生日期；未发现身高、体重、身份证、人脸模板、诊疗资料等结构化采集字段。运动表现、身体相关资料、证书截图仍应按具体风险充分告知并保护。
5. 建议奖励的收件人、手机号、详细地址及物流单号单独处理；申领奖励要求提交 `consent === true` 并保存同意时间。当前没有物流 SDK 或承运商自动下单接口，实际发货受托人、承运商及其信息处理方式须由运营核实。
6. 现有个人信息权利入口可私密提交人工注销申请，提交或工单标为完成不自动删除账户。平台管理员另有删除账户能力，仍为团长的账户需先完成移交；不能将人工工单描述为“一键自动注销”。
7. 大部分业务表没有定时过期清理。已有明确期限的是登录验证码、管理员会话、跑团身份工单部分材料及事件；不能凭空写统一的“保存 180 天后自动删除”。
8. 新增跑史使用独立私密记录及旧成绩的私人覆盖层；不会将新跑史和照片自动加入跑团排行。OCR 在服务器子进程内临时处理用户选择的图片，随包安装中英文模型，不调用外部识别服务；仅在本人核对后保存字段，不保存 OCR 原图或完整识别文本，不进行人脸识别。常见证件号与手机号自动遮盖并不保证识别到全部敏感内容。

## 五、保存、删除与技术边界

- 主要持久数据为 SQLite 数据库和本方媒体目录。文件上传后的元数据保留在业务表；“只保存摘要”只适用于运动文件解析，不适用于用户主动收藏的证书 / 照片 / 视频和业务截图。
- 管理员删除账户会删除计划、成绩、个人收藏、成员关系、签到、活动报名 / 记录、积分 / 兑换、媒体、申请、会费、成绩征集、聚跑、内部赛、跑量、导入映射、目标、雷达、建议 / 奖励、动态互动、部分身份工单等，并尝试移除关联本地媒体文件。代码有“团长先移交”前置条件；数据库事务与磁盘文件清理并非同一事务。
- 创建防滥用记录和身份审核事件部分保留用户 ID / 必要历史摘要，未随账户删除全部立即清空；这些记录的目的、最短期限和去标识化策略需要产品与运营另行确定。不能承诺“注销后立即清除任何关联信息”。
- 删除某条已导入运动后，`wearable_activities` 可保留 ignored 映射及最小摘要，以防同一文件自动恢复已删记录；账户整体删除会移除对应导入连接和映射。
- 普通用户令牌作为本方 Bearer token 使用；部分受保护图片 / 视频使用 URL 查询参数 `t` 传递同一令牌。不得把完整鉴权 URL 放入共享链接、公开截图或错误报告。线上代理访问日志是否过滤敏感查询参数需部署核验。
- Nginx 补丁将来源 IP 通过 `X-Real-IP/X-Forwarded-For` 传入服务端；网络连接本身会使代理 / 服务端接收 IP、请求时间和请求头等。当前业务代码未发现系统化持久保存请求 IP / 访问轨迹的实现，但不能据此断言生产访问日志不存在。日志字段、保存天数、访问人员及销毁机制需运维核实。
- 仓库未提供可核验的生产数据库 / 媒体备份策略、备份副本删除窗口、存储加密 / 密钥管理及灾备地域资料。业务“删除文件”不自动等于所有备份立即清除；协议中的对应承诺须与部署能力一致。
- 解绑微信、退出登录、撤回微信接口授权、撤回某条建议和注销账户，是不同操作；解绑 / 退出不会自动删除已生成的运动和跑团记录。当前缺少统一的“撤回全部业务同意并自动处理历史数据”接口。
- 对用户自行下载、复制、分享的材料，平台只能控制本方存储和展示，不能保证第三方接收人或其他成员设备副本立即删除。协议应明确团长 / 上传者自身的信息保护义务，尤其是团体照片和代填成绩。
