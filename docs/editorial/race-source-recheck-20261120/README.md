# 2026-11-20 赛事来源和参赛指南回查

这次回查处理的是“平台里有这场，但只有赛历、缺本届报名或比赛详情”。这与前一轮的 OCR 清单是两件事：本次按生产赛事逐条筛查来源与关键字段，针对优先名单查官网、主管部门、报名平台、官方公众号和可访问的同届转载。赛事日期和报名日期分开核对；赛历、搜索结果与往届文章只当线索。

- [初次筛查快照](coverage-all.tsv)：434 条记录，包括 412 场真实赛事、22 条演示记录。按北京时间 11 月 20 日划分，185 场真实赛事尚未开赛（含 2 场已确认取消），227 场已过比赛日期。筛查时 24 场未来赛事正文不超过 120 字，另有 26 场触发报名、费用或领物缺项信号，彼此不重复。没有费用或领物关键词不等于没有实际资料；已截止也不等于需补可报名按钮。
- [优先逐场处理](priority.tsv)：50 场的当前状态、已核来源与具体剩余项。未在本轮全部人工校对的赛事不标为完成。
- [最酷目录交叉](zuicool-matches.tsv)：该公开列表的 100 个详情页按名称、日期同时匹配，48 条匹配到库存（11 条属优先名单）。一条同名异日未匹配。仅能定位项目页，不等于采用该来源，也不创建新赛事。赞助冠名差异由人工确认；“GO 千岛野山径”与 11 月 29 日千岛湖公路马拉松不混用。
- [逐批写入与实页验证](verified.json)：记录每场来源范围、无法确认项、备份标记、数据库回读、网页、小程序开发者工具和图片验证。所有批次都先备份生产 SQLite，再逐行检查旧值；比赛总数和数据库结构保持不变，未删旧图或覆盖工作区无关改动。

本轮累计校对并保存 27 场，共 34 次赛事行写入（包括同场后续修订）。27 场的最新内容均检查生产网页 320/390px 和微信开发者工具 390px；42 张新增留存原图在两种网页宽度共通过 84 次加载与放大检查。50 场优先名单中另有 2 场已有本届指南和领物、3 场报名已核而物资安排需按赛事性质复查、18 场仍缺可核来源或关键字段。上述数字不表示所有 412 场真实赛事都已逐图人工校对。

代码在更新本地 `main` 至 `3a66931` 后提交，369 个单元测试通过；采集修复由 [PR #211](https://github.com/xiangxiang222/marathon-platform/pull/211) 合并到 `420dbaa`。这次改的是离线采集：最酷详情页接续访问本届开报文章，优先从中确认官网或官网公布的报名平台；独立搜索读真实目标链接并记录失败，过滤不同年份和无关条目。生产数据使用原有应用器更新，线上沿用已部署指南显示实现。
