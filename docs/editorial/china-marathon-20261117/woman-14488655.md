# 张新艳：跑过障碍的人，怎样走进马拉松

3000米障碍全国纪录、全运会5000米冠军、厦门马拉松中国籍女子冠军。张新艳的长跑版图跨过几个项目，而更长距离从未自动成为更容易的一项。

2021年9月22日，全运会女子5000米决赛最后100米，张新艳、张德顺、许双双才真正分出先后。张新艳15分53秒92夺冠，张德顺15分54秒30，许双双15分54秒38，前三名相差不到半秒。央视赛况记下她在直道上强有力的冲刺。[S2]

这是一段能够具体看见张新艳的比赛：她不只出现在成绩表上，而是在一次接近的竞争里，把最后的速度交给终点。几个月之后，她又走向另一种距离——2022年4月17日杭州马拉松，2小时26分56秒，成为世界田联至今登记的全马PB。[S1]

## 她的履历里，不只有公路

张新艳生于1994年2月9日。世界田联个人纪录中，3000米障碍一栏是2021年4月8日绍兴的9分20秒32，带有全国纪录标记。全运5000米冠军也发生在同一年。这些事实构成她进入马拉松叙事时最鲜明的背景：一个有场地速度、又跨越过障碍的运动员，继续尝试把能力带到更长的公路上。[S1][S2]

但“跨越障碍”在这里首先是实实在在的田径项目，不能被拿来替她编写人生挫折。她何时开始训练，教练怎样决定不同项目之间的安排，本次没有获得足够完整的本人采访。我们能够确认项目履历，无法替她补上改项动机。

杭州的2小时26分56秒，平均配速约为每公里3分29秒。这个平均速度需要维持42.195公里，与5000米终点前的冲刺是两种任务。它们可以共同描绘她的能力，却不能互相代替。缺少完整分段和训练日志，本文不能说全马突破完全来自某种障碍跑训练。[S1]

## 厦门冠军，记录了另一种完成

2023年名古屋，张新艳2小时32分19秒、第19名。2024年无锡，她跑出2小时29分32秒。2025年1月5日厦门，她又以2小时29分04秒获得中国籍女子冠军。[S1][S4][S5]

厦门冠军比杭州PB慢2分08秒。这个差值不削弱冠军的真实性，它说明两场比赛有不同的比较对象：PB在与自己过去的最快成绩比较，组别冠军则由当场竞争决定。她在2025年厦门完成的是后一项任务。[S1][S5]

到2026年1月10日的厦马赛前见面会，张新艳仍然出现在参赛运动员中。她谈到马拉松需要持续挑战自己，希望稳定发挥。这个表述来自她本人，不能延伸成“已经恢复巅峰”或“必将卫冕”的预言。[S3]

次日比赛，世界田联记录她2小时47分48秒、第15名。与上一届相比，时间和名次都有明显变化；没有可靠材料说明原因，就不把它诊断为伤病，也不猜测训练是否失败。过去的纪录与当下的比赛，可以同时放在一个人的履历里。[S1]

## 普通跑者可以借用的，是比较的方法

张新艳的多项目经历，让人容易产生一种直觉：短距离跑得快，长距离自然会更好。她的真实成绩表让这种直觉变得复杂。障碍赛、5000米与马拉松分别检验不同的能力；某一项目的领先，仍需在另一项目的正式比赛中兑现。[S1]

对普通跑者，适合借用的是把不同距离分别记录、分别复盘。短距离进步后，可以提出长距离耐力是否同步的问题，却不必立刻提高全马目标；赢得一次组别比赛后，也不必要求它同时承担PB的证明。

记住张新艳，可以先记住那不到半秒的全运终点，再把画面拉远到厦门42.195公里的赛道。两种距离之间没有一条保证成功的捷径，她已经留下的，正是持续进入不同比赛、交出不同答案的真实轨迹。
