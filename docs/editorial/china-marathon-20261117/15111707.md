# 王佳浩：城市冠军之外，柏林给出另一个答案

宝鸡的第一名与柏林的2小时08分21秒，分别衡量争胜和跑快。王佳浩的成长需要两种坐标。

## 在宝鸡，他先成为一个有名字的冠军

2025年10月26日，宝鸡马拉松，王佳浩以2小时14分46秒夺得男子全程冠军。央视网报道明确介绍，他来自陕西渭南。对读者而言，这是一条可以落到实际比赛与身份上的人物线索，而不是成绩榜里单独一行英文姓名。[S2]

前一年福州马拉松，王佳浩已经获得中国籍男子第三。那是中国籍组别，不是赛事总成绩第三；报道也没有提供他的具体用时，因此不能给那次领奖台补上一个想当然的成绩。[S3]

两条记录能够确认他的竞争经历，却还不足以写出童年如何启蒙、谁把他带入专业体系。这份短档案把成长线放在已经核实的比赛上，等待本人采访补足赛道以外的部分。

## 从212到208，中间有一年没有刷新年表高点

世界田联本人资料列出的全马年度最佳依次包括：2023年杭州2小时16分48秒，2024年苏州2小时12分18秒，2025年南京2小时13分03秒，2026年柏林2小时08分21秒。[S1]

2025年宝鸡的冠军时间慢于当年南京最佳，并不妨碍它成为一场获胜；2026年9月27日柏林，他以2小时08分21秒列第15，又把此前PB提高3分57秒。这一次，在更密集的国际竞争中，名次没有城市冠军醒目，绝对成绩却发生了更大的变化。[S1]

正因如此，王佳浩不宜被压缩成一句从冠军到高手。他已经用不同的比赛回答不同的问题：能否在当日阵容里获胜，以及能否把个人历史成绩推得更远。

## 2026年的终点，并不只有柏林

同一份官方年表还列出塞维利亚2小时11分17秒、南京浦口2小时11分32秒并获第一、米兰2小时31分02秒，以及青岛、密云、吉林等全马经历。这里能确认的是正式结果，不能据此替他诊断赛季安排，或假设某场只是刻意放松跑。[S1]

本文没有取得柏林完整分段和本人训练说明，因此不把3分57秒提高归给某一种训练策略。即便一个结果很鲜明，原因也需要另外收集证据。普通跑者若用他的经历作参照，最有用的是先分清自己的比赛目标：要争取组别位置，还是在适合的赛事中检验最快成绩？两者可以相容，也可能需要不同决策。

本次资料还存在一条同名冲突：一篇南京半马报道与世界田联本人同日赛事记录不能直接对应。为避免拼接人物，本文没有采用那条经历。11月17日，本次通过世界田联另一官方本人页入口重新核验了他的记录。王佳浩在柏林跑出的新坐标值得关注，档案本身也应保持这种可检验性。[S1]
