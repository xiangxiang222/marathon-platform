# 赛道人物：中国马拉松运动员档案

项目内已接入「跑圈动态 → 运动员 → 中国马拉松运动员档案」。这是独立的有日期人物专题，使用认可全马PB排序；原有2026赛季最佳各100人数据接口继续保留。

资料截止2026-11-17，男女各20人，正文合计35,665汉字（不计英文、数字、标点和来源表）。按用户补充要求，篇幅随真实材料调整，单篇约564—2075汉字：采访丰富者写较长人物故事，材料有限者采用有明确分析边界的短专题。每人有自己的中心问题和代表比赛，不补造童年、训练、伤病或心理细节。

- [40篇正文审稿目录](profiles-index.md)：可直接阅读每篇最终稿及原始来源。
- [完整名单与证据审计](ranking-audit.md)：包括40人名单、38名更快历史PB候选的排除依据、同PB规则、身份范围和资料限制。
- [合并资料卡](research-cards.json)：逐人事实、来源、现役记录、研究问题与冲突处理。
- [机器名单](research-roster.json)、[排除记录](ranking-exclusions.json)、[退役检索记录](retirement-searches.json)。

## 必须保留的口径

沿用项目的世界田联CHN体育登记范围，不把它表述成私人护照查验，也不自动包含HKG、MAC、TPE登记选手。现役按2024-11-17至2026-11-17任一正式田径或路跑项目实际参赛筛选，并在本轮公开材料中检查是否宣布退出竞技。用户已明确：离开专业队但继续参加竞技者计入。

因此，任秀娟以2024年12月中国田协10公里赛事作为近期参赛依据；孙腊梅汕头成绩标有UNC，只作为正式出赛证据，排名仍采用其合法PB。这不等于每位入选者近两年都参加了全马，或仍具有国家队、专业队身份。世界田联不覆盖全部地方赛事，未检索到退出公告也不是对负面事实的绝对证明。以上限制随名单审计保留。

相同PB并列，如桑吉东知与蒋发坤同列男子第14。边界若需固定20篇，依较早取得该PB者优先，同日用WAID固定顺序；这不表示综合实力更强。本轮最终边界没有同成绩争议。

## 图文与阅读

40人各有一张原创年度成绩图，使用官方年度最佳数据，最多选择8个赛季；条长从零表示总用时，不插补缺失年份。已沿用8张能识别人物、保留出处的既有人物照片；没有给缺图人物合成照片，也没有把同名主持人、快递员或无法定位个人的合照当作头像。

Web与小程序均支持目录、完整正文、逐段来源标记、PB和近期比赛信息、本设备收藏、分享。Web引注定位到来源表，可打开原始网页；小程序点击引注或来源会复制原始链接，避免依赖未配置的第三方业务域名。收藏保存在本设备，未宣称跨设备同步。

## 数据与代码

最终公开数据：`shared/china-marathon-feature.json`。API：`GET /marathon/api/content/profiles?type=athlete&collection=china-marathon&gender=men|women`。详情沿用既有人物ID和详情接口；新入选历史人物也保持历史可用ID。专题与自动赛季采集分开，采集脚本不会覆盖原创正文。管理员正文修订、下架仍有效，专题的PB和排名依据保持来自有日期的来源表。

`build-marathon-feature.cjs`只合并已研究的作者稿，不生成文章。它检查40人数量、唯一身份、PB排序、活动窗口和引注绑定，并输出公开数据、合并资料卡及Markdown审稿目录。`render-marathon-feature.cjs`生成PNG及可编辑SVG；图表源文件和PNG位于`web/public/images/athlete-feature/`，PNG供小程序使用。

```sh
npm run content:athletes:build
npm run test:athlete-feature
```

修改名单必须先补对应资料卡、作者稿和排名审计，再重建；不要把现有赛季榜截取前20当成PB人物榜。`evidence/`保存官方成绩数据核对快照；`sources/`和`root-sources/`为本地第三方阅读缓存，不提交到公开仓库，也不会作为原文全文在产品中发布。原创稿、事实资料卡和原始来源链接均随专题保留，构建不依赖这些阅读缓存。
