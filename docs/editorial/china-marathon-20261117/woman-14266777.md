# 白雪：世界冠军之后，还有一张哈尔滨成绩单

2009年柏林世锦赛金牌，和2025年哈尔滨2小时54分21秒，属于同一位跑者。白雪的档案需要容纳竞技巅峰，也需要准确看见她后来仍参加的比赛。

2025年8月31日，世界田联在白雪的本人资料下收录哈尔滨马拉松成绩：2小时54分21秒，第19名。她出生于1988年12月13日，比赛时36岁。[S1]

这条记录把她带回本专题近24个月正式参赛的筛选窗口。它没有写她正在国家队训练，也没有给出专业或大众报名身份；本文据此确认的是正式参赛，不能把它包装成重返专业队或重新冲击世界冠军的声明。

## 柏林，那块有明确位置的金牌

2009年8月23日，白雪在柏林世锦赛女子马拉松以2小时25分15秒夺冠。世界田联的荣誉记录把冠军、时间与日期一并保留。这是她在中国马拉松史中最具辨识度的一场比赛。[S1]

但她的全马PB来自另一场：2008年1月5日厦门2小时23分27秒。世锦赛夺冠的时间比PB慢1分48秒。只看速度，厦门更快；只看世界大赛的冠军结果，柏林又拥有无法被这个时间差消去的意义。[S1]

柏林冠军时间的平均配速约为每公里3分27秒，厦门PB约为3分24秒。这里的计算帮助读者理解两场比赛的总速度，不能还原柏林每次集团分化与最终进攻。本次没有取得完整官方分段，因此不补写一个未经证实的突围地点。[S1]

## 公路冠军背后，也有跑道

白雪并非只有马拉松一种竞技经历。2005年亚洲田径锦标赛，她赢得5000米与10000米；2009年10000米跑出31分17秒62，世界田联将其列为个人最好成绩。场地与公路共同构成了她早期的长跑版图。[S1]

这些记录说明她曾在多个距离参与高水平竞争，却不足以替她写出训练课表。她如何开始练跑、专业生涯中每次调整的原因，本次材料没有给出完整本人叙述。年龄和比赛地点都不能代替成长经历的证据。

2015年，央视报道将白雪列在北京世锦赛受邀解说嘉宾之中。那份名单让读者看到，赛场之外她也曾通过解说角色参与田径传播。报道没有明确给出她本人准确的退役日期，不能把对一群体育名宿的概述当作个人职业状态证明。[S2]

## 用两种时间阅读同一个人

从柏林世锦赛到2025年哈尔滨，相隔十六年。哈尔滨的2小时54分21秒，比她2008年的PB慢30分54秒。这个时间差是真实的，但没有当代采访和训练资料，不能擅自用“为了某个目标复出”解释这次参赛。[S1]

对她最基本的尊重，是既不隐藏当前成绩，也不让当前成绩覆盖过去的冠军。PB榜排列的是各人的历史最快合法全马结果，本专题的“现役”则按近24个月正式参赛判断，两者都不是当前国家队身份或综合实力的同义词。

普通跑者可以从这里得到一个具体启发：把曾经最快的自己和今天能够完成的任务分开记录。两者可以相互照亮，未必需要每次都相互竞争。这是一种复盘建议，不是要求大众模仿她的训练或参赛频率。

白雪值得被记住，首先因为那场有官方记录的世界大赛胜利；也因为多年之后，她的姓名仍出现在一张新的正式成绩单上。档案不需要替她宣布新的职业目标，只需要把这两个真实时刻，准确地交到读者手里。
