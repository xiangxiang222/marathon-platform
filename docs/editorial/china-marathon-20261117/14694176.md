# 索朗才仁：从212平台，再向208迈一步

他的进步没有发生在每一个赛季。2026年无锡的2小时08分20秒，需要放回更长的成绩曲线里理解。

## 2小时08分20秒，突破的是哪一段过去

2026年3月22日，无锡马拉松，索朗才仁以2小时08分20秒获得总第六，刷新个人最佳。与他2024年无锡的2小时10分31秒相比，快了2分11秒；与2019年柏林年表中的2小时15分03秒相比，则快6分43秒。[S1]

两个差值描绘了不同距离的成长：前者是最近一次PB之间的变化，后者是这份官方年表里两个赛季高点之间的变化。都不能被简化为几年训练线性兑换了几分钟。

## 三个212赛季之间，还有更慢的一年

世界田联资料显示，索朗才仁2020年南京年度最佳2小时12分13秒，2022年杭州2小时16分12秒，2023年无锡2小时12分47秒。到2024年，他跑到2小时10分31秒；2025年年度最佳又是2小时12分10秒，随后才到2026年的2小时08分20秒。[S1]

如果只保留最初和最终的成绩，会得到一条漂亮的上升斜线；保留中间年份，会看到平台和回摆。公开记录没有交代每次波动的训练或健康原因，所以本文不把较慢年份写成伤病年，也不把下一次突破归因为未经核实的某位教练或某种课表。

## 深圳的冠军，发生在半程赛道

2023年2月19日实际举行的2022深圳马拉松，索朗才仁拿到男子半程冠军，扎西多杰与洛桑曲杰列第二、第三。赛事名称沿用2022，举办日期却在2023年；这两种年份都需要保留，才能避免把参赛经历错放一年。[S2]

这条履历让人知道，他也在21.0975公里距离参与争胜。不过，报道没有给出他的半程用时，不能用冠军身份反算速度，也不能把赛事全程线路的细节套到半程比赛中。项目相同于路跑，不代表距离和路线完全相同。[S2]

## 一个PB，还不是一套公开的突破方法

2026年，官方资料另列仁寿半马1小时02分42秒、兰州全马2小时21分00秒、北京全马2小时14分03秒。以PB的平均值换算，无锡全程约每公里3分02.5秒；但没有完整分段，我们不知道他怎样从前半程安排到最后五公里。[S1]

把这些限制写清楚，仍然可以得到一个具体认识：索朗才仁已经跑进208区间，同一赛季的全部比赛却没有停留在那个区间。他不是一行最好成绩的化身，而是在不同赛事中继续面对新的竞争。

对遇到平台的普通跑者，他的年表提供的是观察尺度：以多季记录辨认变化，同时为每场留下当时的训练和路线背景。成绩表能显示平台之后出现了突破，只有更多当事人资料才能解释它如何发生。索朗才仁接下来的故事，也值得从这个问题继续追踪。
