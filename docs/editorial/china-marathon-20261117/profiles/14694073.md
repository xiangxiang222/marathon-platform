# 陈天宇：三次北京，三种成绩的分量

个人最佳、总成绩领奖台和赛季回升，都发生在北京。把三场比赛并排，才能看到陈天宇不止一种竞技价值。

## 更慢的一次，却站上了领奖台

2024年11月3日，北京马拉松，陈天宇以2小时09分48秒获得男子总成绩第三。冠军莱米·伯哈努·海勒2小时09分16秒，亚军贝特维尔·基贝特·琼巴2小时09分30秒；陈天宇距离前两名分别是32秒和18秒。[S2](https://news.cctv.com/2024/11/03/ARTIqFtgJvXG0zniEkBUcdV1241103.shtml)

这不是他的PB。世界田联记录中的个人最佳，是2023年10月29日北京马拉松的2小时08分11秒，比2024年那次快1分37秒。更慢的终点时间与醒目的总成绩领奖台同时出现，正好说明PB与名次回答不同问题：一个测量个人历史最快表现，一个记录当天与同场对手竞争的结果。[S1](https://worldathletics.org/athletes/athlete=14694073)[S2](https://news.cctv.com/2024/11/03/ARTIqFtgJvXG0zniEkBUcdV1241103.shtml)

报道还列出2024年比赛从天安门广场出发，终点在奥林匹克公园中心区。但本文没有取得陈天宇逐段时间、风向和对手位置变化，不能仅凭最后18秒差距判断他是否曾有机会冲击亚军，也不能把领奖台写成最后一公里逆转。[S2](https://news.cctv.com/2024/11/03/ARTIqFtgJvXG0zniEkBUcdV1241103.shtml)

## 北京之前，他经历过一个并不平滑的上升过程

世界田联年度最佳中，陈天宇2018年衡水2小时18分14秒，2019年北京2小时15分16秒，2021年徐州2小时13分15秒。2022年厦门的年度最佳是2小时22分52秒，随后2023年北京来到2小时08分11秒。[S1](https://worldathletics.org/athletes/athlete=14694073)

成绩表可以确认那几年结果有起伏，却不能替人物补写病伤原因。没有可靠采访，所谓低谷蛰伏或重新找回信心都只是写作者的想象。因此，这份档案把变化留在可验证的层面：2023年，陈天宇确实跑出了明显不同于此前记录的全马成绩。

## 第三次北京，把当季成绩重新拉到209

2026年，他在香港、大阪、无锡和兰州均有全马记录；到了10月18日北京，以2小时09分09秒获得第五名，成为当季最佳。相较2024年北京，这一场快了39秒，但名次从第三变成第五。不同年份的竞争密度变化，再次说明为什么不能只拿排名倒推绝对能力。[S1](https://worldathletics.org/athletes/athlete=14694073)

2024、2025、2026三个赛季的年度最佳分别为2小时09分31秒、2小时09分33秒和2小时09分09秒。它们都慢于2023年PB，又集中在一个较小区间里。对一位持续参赛的运动员，这种多季有效成绩同样构成观察材料，不该因为暂未更新PB而被删掉。[S1](https://worldathletics.org/athletes/athlete=14694073)

普通跑者可以仿照这三次北京，为自己的比赛同时保留三列：成绩、同组名次、当时的赛季处境。同一条路线也可能遇到不同条件，这三列仍不能完成全部解释，却能避免把一次PB之外的好比赛误读成退步。陈天宇值得被记住的，是他在同一座城市里留下了三种不同的竞争成果。
