# 高鹏：离最好的自己，一分二十秒

北京的PB与无锡的新赛季，构成一段仍在缩短的距离。

2026年3月22日无锡，高鹏以2小时10分54秒完赛，获第十五名。他的PB仍是2023年10月29日北京的2:09:34。两者相差1分20秒。这个差距既没有带来新纪录，也不是一句“状态下滑”能够概括的结果：与2025年年度最佳2:12:37相比，他已经快了1分43秒。[S1](https://worldathletics.org/athletes/pr-of-china/peng-gao-14750614)

## 从衡水湖到北京

世界田联收录的全马年度最佳中，2018年衡水湖是2:17:55，2019年东莞为2:15:56，2020年南京进入2:13:04。2021年全运会2:15:39、2022年厦门2:13:57，则让这条成绩线出现反复。到2023年北京的2:09:34，他比前一年年度最佳快4分23秒，首次在该序列中迈入2小时10分以内。[S1](https://worldathletics.org/athletes/pr-of-china/peng-gao-14750614)

这个进步幅度值得记录，但缺少他本人的训练访谈，就不能把突破写成某种特定课表的成功。成长经历、教练关系与伤病也不应从比赛成绩中倒推。我们目前能说明的是，长期参赛的记录中出现过明确的加速，也出现过未能刷新PB的年份。

## 复盘一分二十秒

2:09:34与2:10:54的全程平均配速，分别约为每公里3分04秒和3分06秒。平均每公里不到两秒的差距，到了终点便是80秒。这种尺度有助于理解精英比赛对持续输出的要求，却不能证明他在无锡每一公里都慢了同样多。

2026年2月大阪为2:15:53，3月无锡2:10:54，10月北京2:13:51。一个赛季中，终点时间随比赛而变化。我们没有逐项比较三场天气、路线与配速集团，所以不把这些差异全部解释成个人能力的升降。[S1](https://worldathletics.org/athletes/pr-of-china/peng-gao-14750614)

## 追近PB，也是一种可读的故事

高鹏值得关注的，是他让人看见巅峰成绩之后仍有具体的竞争工作。2024年年度最佳2:11:59，2025年2:12:37，再到2026年2:10:54，距离自己的纪录有远有近。只有连续记录，读者才能知道新一场表现处在怎样的位置。[S1](https://worldathletics.org/athletes/pr-of-china/peng-gao-14750614)

普通跑者若正经历一个没有新PB的赛季，可以借用这套比较方法：先看自己与近期表现的关系，再看与生涯最佳的距离，并把比赛条件写进复盘。它不是要求每一次都逼近纪录，而是让“我这次跑得怎样”得到一个比单独终点数字更完整的回答。
