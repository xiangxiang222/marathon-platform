# 毛金虎：把10公里的速度，带进全马207

从亚锦赛万米第13名，到国内10公里冠军，再到无锡全马总亚军，三个距离显示出同一个人的不同能力。

## 无锡领奖台上，第一次看清他的全马尺度

2026年3月22日，无锡马拉松，毛金虎跑出2小时07分36秒，获得男子总亚军。冠军凯马尔·侯赛因的成绩是2小时07分07秒，两人相差29秒。央视新闻明确将这场表现记作毛金虎个人最好成绩，世界田联本人页也收录了同样的合法全马PB。[S1](https://worldathletics.org/athletes/athlete=14913625)[S2](https://news.cctv.com/2026/03/22/ARTIFE8kFCGQio2oTQCoi5PH260322.shtml)

它很容易被写成一位新锐横空出世，但在此之前，毛金虎已经出现在其他距离的正式比赛中。理解他的速度，先看42.195公里以外的赛道更有帮助。

## 同一个人，在三个距离里有三个位置

2025年5月的亚洲田径锦标赛，毛金虎参加男子10000米，获得第13名。到12月28日，四川眉山中国田径协会10公里精英赛总决赛，他以28分59秒夺冠，蒋发坤与丰配友分获第二、第三。不同比赛阵容和条件不同，前一场的名次不能直接预测后一场，但这些记录说明，他进入全马207区间之前已经具有正式场地和公路比赛经历。[S3](https://sports.cctv.com/2025/12/29/ARTID8ZhBErGKPEtnBjJqckA251229.shtml)[S4](https://sports.cctv.com/2025/05/28/ARTIHERLhoV7FoNkLGZ2eziI250528.shtml)

28分59秒的10公里，平均每公里约2分53.9秒；2小时07分36秒的全马，平均每公里约3分01.4秒。两个平均值相差约7.5秒。本文只把它们用来说明距离延长后速度必须怎样重新分配，不能据此认定这就是毛金虎训练中的阈值配速，更不能拿来给其他运动员套成绩公式。[S1](https://worldathletics.org/athletes/athlete=14913625)[S3](https://sports.cctv.com/2025/12/29/ARTID8ZhBErGKPEtnBjJqckA251229.shtml)

从10公里冠军到马拉松亚军，值得研究的是速度如何被延长，而不是简单把四段10公里相加。本次未取得无锡完整分段、补给和训练访谈，因此无法确定他的后程优势来自哪一种训练调整。

## PB之后，同样有不整齐的赛果

世界田联2026年资料还收录毛金虎兰州全马2小时27分32秒、北京2小时10分39秒；场地比赛中，蚌埠10000米29分26秒43获得第一，衢州全国锦标赛10000米30分44秒13列第19，5000米14分00秒61列第三。[S1](https://worldathletics.org/athletes/athlete=14913625)

这些结果没有组成一条每次都更快的线。也没有足够证据让作者替他解释某一场是训练赛、天气不利还是身体问题。把它们保留在档案里，才不会让一个醒目的PB吞掉全部赛季。

普通跑者从毛金虎身上能得到的具体启发，是给自己的成绩建立多距离档案：短距离说明速度储备，长距离检验能否把它延续。两者应当互相参照，不能互相担保。毛金虎最值得持续关注的问题，也正是他接下来如何让不同距离的能力在全马中继续汇合。
