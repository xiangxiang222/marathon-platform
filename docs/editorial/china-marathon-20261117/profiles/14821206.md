# 贾俄仁加：在柏林打开的门，如何带到下一场比赛

从2:22到2:08的进程，和个人巅峰之后并不笔直的赛季。

2024年9月29日，柏林马拉松的成绩表上，贾俄仁加交出2小时08分32秒。这是世界田联认可的全马个人最佳。对读者而言，这个数字最有意味的地方，不只是跨进了哪个整分区间，而是同一座城市在他的履历中出现了三次：2019年的2:14:38，2023年的2:09:54，以及这一次的2:08:32。[S1](https://worldathletics.org/athletes/pr-of-china/erenjia-jia-14821206)

## 同一座城市，三次刻度

2019年12月，北京青年报记者褚鹏在报道中国马拉松奖金政策时，把贾俄仁加与杨乐列为没有专业训练背景的民间跑者，与体制内专业选手并置。这是对他当时入行背景的媒体描述，不能自动延伸为他今天仍完全依靠业余训练。它至少让早期广州到柏林的成绩变化，多了一层值得追问的背景：更开放的公路比赛，如何让不同来路的跑者被看见？[S2](https://sports.cctv.com/2019/12/17/ARTI6F65cjRLJmDOBzMeJpcv191217.shtml)

2017年广州2:22:31、2018年广州2:18:33，是世界田联资料中更早的全马年度最佳记录。到2019年柏林，他跑进2小时15分；2020年上海则把年度最佳推进至2:12:44。这里不能把“最早收录”写成“第一次跑马”，资料也没有告诉我们这些进步对应怎样的成长环境或训练安排。能够确定的是，这条成绩轨迹跨越多年，2:08并非从一场比赛突然开始。[S1](https://worldathletics.org/athletes/pr-of-china/erenjia-jia-14821206)

2023年至2024年，两次柏林成绩又缩短82秒。换算为全程平均配速，大约从每公里3分05秒降至3分03秒。两秒左右的每公里差异，累积起来足以改变一名选手的PB位置。不过，平均数只说明总时间与距离的关系；没有获得他的逐段计时，就不能据此宣称他采取了均匀配速，或在哪一公里主动加速。

## 比最快的一天更宽的赛季

2025年大阪，他的年度最佳是2:11:34；2026年无锡为2:10:22。相较柏林PB，这两场都更慢，但并不能据此判定他“失去意志”或者“训练出了问题”。成绩资料没有提供这样的因果证据。它们能提出一个更好的观察问题：选手在新的赛道和赛历中，怎样把曾经达到的速度再次组织起来？[S1](https://worldathletics.org/athletes/pr-of-china/erenjia-jia-14821206)

2026年3月15日，他在仁寿半马跑出1:02:07，刷新该项目PB；一周后在无锡完成2:10:22。两个项目的纪录并不同步，也提醒我们，半程速度能够成为观察全马能力的一条线索，却不能直接用翻倍法预测42.195公里。[S1](https://worldathletics.org/athletes/pr-of-china/erenjia-jia-14821206)

## 从纪录里学习，保留现实的条件

贾俄仁加值得普通跑者持续关注的，是“突破”和“重复突破”之间的距离。成绩进步可以跨越多年，个人最佳之后也可能出现几个未刷新PB的赛季。把每场成绩都视为一次独立的能力检验，比要求自己次次进步更有帮助。

这并不意味着可以复制精英运动员的参赛间隔。这里讨论的是观察方法：记录比赛目标、当日条件和自身恢复状态，再决定如何比较。关于他的出身、教练、训练量和伤病，本稿尚无足够本人采访，因此不把成绩波动改写成未经证实的苦难故事。读者先记住那个在柏林逐步打开速度的人，再等待下一次有证据的新篇章。
