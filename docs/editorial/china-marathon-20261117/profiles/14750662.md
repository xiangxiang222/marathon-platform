# 彭建华：两次相隔三年的两小时十分以内

2019年的PB与2023年的接近，提示我们用更长的时间理解一名选手。

2019年12月8日，广州马拉松，彭建华跑出2小时09分57秒。三年多之后，2023年3月19日首尔，他又交出2:09:59。只差两秒，两个终点相隔数年。与其把他的职业生涯写成一个单点纪录，不如从这两次接近的表现开始读。[S1](https://worldathletics.org/athletes/pr-of-china/jianhua-peng-14750662)

## 这两秒之间，有哪些已经发生的比赛

2019年的一篇北京青年报报道，为这次转向提供了当年的现场语境：记者褚鹏将彭建华描述为从万米赛场走向马拉松的选手，并确认2019年是他开始参加马拉松的年份。报道也记录了他对高额破纪录奖金的兴趣。赛事机会和现实激励参与了这段选择，但这并不等于奖金能够单独解释一次成绩突破。[S2](https://sports.cctv.com/2019/12/17/ARTI6F65cjRLJmDOBzMeJpcv191217.shtml)

世界田联记录显示，彭建华在2018年全国锦标赛5000米以14:07.06夺冠，10000米以29:17.98夺冠；2019年亚洲田径锦标赛10000米以29:40.32列第六。2020年全国锦标赛5000米，他又以14:13.78获得第一。全马之前及其间，他已在场地项目留下正式竞争记录。[S1](https://worldathletics.org/athletes/pr-of-china/jianhua-peng-14750662)

2021年4月11日徐州全国马拉松锦标赛，他以2:11:16获得冠军。这比广州PB慢1分19秒，却拥有冠军这一不同维度的意义。PB描述的是个人最快合法成绩，名次描述的是当场竞争结果；两者一起读，才不会让一次锦标赛冠军被简单压缩成“没有跑出最好成绩”。[S1](https://worldathletics.org/athletes/pr-of-china/jianhua-peng-14750662)

## 首尔再接近

2:09:57与2:09:59在全程平均配速上几乎没有可感知的区别，都是约每公里3分05秒。然而终点时间相近，并不能证明两场比赛以相同方式完成。缺少完整分段和经过核验的比赛进程，我们不能写出某一次“更稳”、某一次“更冒险”的结论。

2022年厦门年度最佳为2:14:29，2023年首尔又回到2小时10分以内。对照这些结果，能够看到表现的反复和再度接近；至于波动对应怎样的身体情况、训练调整或个人选择，现有资料没有提供充分答案。[S1](https://worldathletics.org/athletes/pr-of-china/jianhua-peng-14750662)

## 继续参赛，不等于仍处巅峰

世界田联收录了他2026年9月13日哈尔滨马拉松的2:34:16、第十七名。这条正式比赛记录支持本专题对“近24个月参赛”的筛选，却不能使一个生涯PB排名自动变成当前实力排名。2024年衡水湖2:31:51与2026年哈尔滨的结果，也必须与2019年的纪录明确区分。[S1](https://worldathletics.org/athletes/pr-of-china/jianhua-peng-14750662)

普通跑者值得读他的原因，是一个成绩可以有很长的生命，而对运动员的判断需要不断更新。回看最好的一天，可以知道自己曾经达到哪里；评估现在的训练和目标，则应依据近期证据。彭建华的档案应当保留这种时间感：尊重过去的速度，记录眼下的比赛，也不给尚未核实的原因贴上伤病或退役标签。
