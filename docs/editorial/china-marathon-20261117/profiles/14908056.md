# 刘敏：在纪录附近，建立自己的存在感

不每次刷新PB，刘敏怎样用连续表现留下分量？

## 20秒，也是一场进步
2025年3月23日，刘敏在无锡跑出2:28:16。她2024年北京的年度最佳是2:28:36，两者相差20秒。对已跑进两小时半的选手，这种幅度并不应该被更大的突破叙事淹没。这是相对于她已有PB的一次实际提高。[S1](https://worldathletics.org/athletes/china/min-liu-14908056)

此前2023年北京的年度最好为2:32:05。两步连起来看，到2025年共推进3分49秒。没有公开训练采访，无法确定成绩改善来自何种负荷调整；终点记录已经足够说明进步本身。[S1](https://worldathletics.org/athletes/china/min-liu-14908056)

## 2026年初的三次接近
一月重庆2:29:23，三月东京2:30:03，同月无锡2:29:17。三场全马整体用时分布在不到一分钟的范围内，都离PB不远。这里的接近，是跨比赛结果的比较，不意味着天气、路线、战术完全相同。[S1](https://worldathletics.org/athletes/china/min-liu-14908056)

无锡2:29:17距离PB61秒，平均每公里约差1.4秒。这是整体用时的接近程度，不能替代尚缺的个人分段。[S1](https://worldathletics.org/athletes/china/min-liu-14908056)

## 短距离给档案增加侧面
她的官方记录包括半马1:09:36、10公里32:10，以及5000米15:43.49。2026年也有多场10公里正式结果，其中南京站32:42夺冠。赛事可以证明她在不同距离保持参赛，不等于她公开了一份可以照做的训练计划。[S1](https://worldathletics.org/athletes/china/min-liu-14908056)

秋天她在太原跑出2:30:40，获总第四；北京2:32:10，总第十四。状态变化应完整保留。相同运动员换一场比赛，名次也受对手影响，不能把名次下降的幅度直接解释成个人能力下降的幅度。[S1](https://worldathletics.org/athletes/china/min-liu-14908056)

## 让持续表现也值得收藏
刘敏的鲜明之处，是她的故事可以用一组靠得很近的数字来读。单次PB占据标题，更多普通赛日则回答她能把自己带到什么位置。对持续关注中国女子马拉松的读者，这类选手让竞争的厚度变得具体。

普通跑者可以从她这里借用一种记录习惯：除了最快的一次，也留出空间记录接近最好水平的比赛，观察结果的分布。要判断训练有没有起效，一次特别好的发挥和一组可重复的表现，能回答不同的问题。
