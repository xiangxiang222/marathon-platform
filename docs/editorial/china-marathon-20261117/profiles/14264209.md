# 朱晓琳：从奥运会第四名，到仍在到来的起跑线

北京、伦敦、石家庄、雄安——朱晓琳的比赛地图跨越不同阶段。她的特点，不只在早年的快，也在多场世界大赛中留下的稳定位置。

2008年8月17日，北京奥运会女子马拉松，朱晓琳以2小时27分16秒获得第四名。四年后的伦敦，她跑得更快，2小时24分48秒；世界田联现行荣誉记录列她为第五名。两场奥运会，都把她放在世界最强选手的前列。[S1](https://worldathletics.org/athletes/athlete=14264209)

从这两行成绩理解朱晓琳，比简单贴一个“遗憾”的标签更准确。她在伦敦比北京快2分28秒，最终名次却在其后。时间与对手的位置，从来不是同一件事。伦敦名次采用当前官方记录，不沿用部分早期报道中的旧名次，也不猜测后续更正原因。[S1](https://worldathletics.org/athletes/athlete=14264209)

## 一串世界大赛中的位置

朱晓琳生于1984年2月20日，全马PB是2002年10月13日北京的2小时23分57秒。2007年大阪世锦赛，她2小时31分21秒、第四；2009年柏林世锦赛2小时26分08秒、第五；2011年大邱世锦赛2小时29分58秒、第六。[S1](https://worldathletics.org/athletes/athlete=14264209)

几场比赛的时间差不小，名次却连续处于前六。这是她履历里很有辨识度的部分：在不同世界大赛中完成高位置的竞争。它不能自动证明某一项战术，但提示读者别只按PB之外有没有更快成绩来判断一段生涯。[S1](https://worldathletics.org/athletes/athlete=14264209)

伦敦的2小时24分48秒，距离个人PB51秒，平均每公里约3分26秒。本次未取得她这场奥运会的完整分段与可靠训练记录，因此分析停留在结果尺度，不推断哪一公里改变了名次。

## 后来的比赛，没有停在旧照片里

2025年3月30日石家庄马拉松，世界田联登记她2小时38分12秒、第三名；同年大连2小时43分06秒，北京2小时42分13秒。这些成绩出现在同一世界田联编号之下，为她在近24个月内正式参赛提供了直接证据。[S1](https://worldathletics.org/athletes/athlete=14264209)

2026年4月12日雄安马拉松，央视赛况又报道朱晓琳以2小时45分29秒赢得女子全马冠军。近年的比赛时间与早年巅峰之间有明显距离，而冠军仍然是一场有具体对手、具体终点的真实结果。[S2](https://sports.cctv.com/2026/04/13/ARTI5kmfQ2Y0FLmzLPHuwZD3260413.shtml)

她现在是否属于专业队、每天怎样训练，材料没有给出足够说明。专题以正式参赛判断活动状态，不据此称她正在国家队备战，也不为多年间的成绩变化补写伤病诊断。

普通跑者从朱晓琳身上可以借用的，是为不同比赛保存不同任务：世界大赛的排名、最快全马的时间、后来某一场比赛的完成度，各有自己的坐标。旧PB不必被删掉，新的成绩也不需要躲在它后面。

记住朱晓琳，可以记住她连续几届世界大赛里的前六名，也记住多年后石家庄和雄安的终点。前者说明她曾在怎样的竞争里跑到前面，后者说明这份履历仍然继续。
