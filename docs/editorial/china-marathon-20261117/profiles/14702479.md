# 李美珍：在同一座城市，把两小时半一步步跑远

三次无锡成绩，怎样记录李美珍持续向前的能力？

## 从厦门的一次兑现开始
2026年1月11日，李美珍在厦门跑出2:27:24，获得女子国内组冠军。央视记者的现场报道确认了这个结果；世界田联的总体名次是第五。把这两个名次同时写清楚，才能看见她面对的完整竞争环境。她跨过了自己的旧纪录，但两个月后，这个数字又将被更新。[S1](https://worldathletics.org/athletes/china/meizhen-li-14702479)[S2](https://local.cctv.com/2026/01/11/ARTIhQI0RYgDsehFcxkDv1ZV260111.shtml)

她在无锡跑出的2:25:06，把厦门的成绩再推进2分18秒。对刚认识她的读者，两场比赛足以构成一个清楚的开头：她在2026年初连续把已有能力转化成更快的全马，进步发生在实际终点线上。[S1](https://worldathletics.org/athletes/china/meizhen-li-14702479)

## 2:30:01留下的那一秒
世界田联收录的2023年无锡成绩是2:30:01；2025年同一赛事，她跑到2:27:51；2026年再到2:25:06。从第一次到第三次，差了4分55秒。相同城市便于形成连续观察，但不同年份的天气、路线细节和对手并不自动相同，不能把全部差额归给某种训练改变。[S1](https://worldathletics.org/athletes/china/meizhen-li-14702479)

这条轨迹还有不整齐的地方：2024年的全马年度最佳是上海的2:35:00。进步并非每年沿一条直线发生。把那个赛季留下来，李美珍的故事才有真实的时间厚度。现有资料不足以解释当年的状态原因，成绩变慢也不能直接改写成受伤故事。[S1](https://worldathletics.org/athletes/china/meizhen-li-14702479)

## 快，是多个距离共同留下的痕迹
她的官方资料里有2016年的1500米记录，也有2025年的5000米15:47.25、10000米32:32.38，以及半马1:09:34。这些记录说明她的竞技经历跨越场地和公路；最早被收录的成绩不能当作她第一次训练的日期。[S1](https://worldathletics.org/athletes/china/meizhen-li-14702479)

2026年无锡全马平均每公里约3分26秒。这个平均值让2:25:06有了可理解的速度尺度；由于缺少完整个人分段，本文不进一步判断她在哪一公里决定了比赛。[S1](https://worldathletics.org/athletes/china/meizhen-li-14702479)

## 把注意力留给下一次转换
无锡之后，她在4月无锡马山10公里赛跑出32:57并夺冠，5月泸水10公里赛再获第一。接下来的观察重点，是这些距离的比赛能力何时能再次在全马终点汇合。[S1](https://worldathletics.org/athletes/china/meizhen-li-14702479)

李美珍让普通跑者看见的，是如何把观察单位从一场比赛扩展到几季：保留表现不佳的年份，用相同距离复核进步，也给短距离能力转化为全马留出时间。她的下一项值得关注的事，是能否持续接近2:25这一新水平，而非每次出发都必须刷新纪录。
