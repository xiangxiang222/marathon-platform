# 李芷萱：七年后，距离最快的自己还有38秒

2019年名古屋2小时26分15秒，2026年东京2小时26分53秒。两场比赛之间隔着七年，时间只差38秒。把李芷萱的履历展开，会发现长期竞争力有时就藏在PB旁边。

2018年12月2日，上海女子10公里精英赛，李芷萱以32分42秒夺冠。比赛结束，她谈的却是更长的距离：未来重心仍放在全马，这次短距离比赛承担以赛代练的作用，之后要进入冬训。[S4](https://sports.cctv.com/2018/12/02/ARTIBcsO1ODXpCIuYcIM6haI181202.shtml)

她当时已经是上海马拉松中国籍女子冠军。10公里的胜利因此有两种位置：它是一场独立比赛的冠军，也是通往全马目标的一段积累。她没有在采访中把每次获胜都说成终点，而是把冬训和接下来的竞争接在一起。[S4](https://sports.cctv.com/2018/12/02/ARTIBcsO1ODXpCIuYcIM6haI181202.shtml)

几个月后，2019年3月10日，她在名古屋跑出2小时26分15秒。这条成绩至今仍是世界田联登记的全马PB。2026年3月1日东京，她完成2小时26分53秒，获得第13名；七年过去，距离旧PB是38秒。[S1](https://worldathletics.org/athletes/pr-of-china/zhixuan-li-14376349)

## 一条不只靠刷新纪录延续的路

世界田联年度最佳记录表明，李芷萱的全马成绩并非只有2019年这一个亮点。2020年上海，她跑出2小时26分39秒；2023年名古屋，她以2小时26分28秒获得第八名，达到当时巴黎奥运会女子马拉松参赛标准。[S1](https://worldathletics.org/athletes/pr-of-china/zhixuan-li-14376349)[S3](https://sports.cctv.com/2023/03/13/ARTIj0WhDe31ghzVSKKVU3Hs230313.shtml)[S5](https://sports.cctv.com/2020/12/06/ARTIus3czLH0AtYBZyK3oQUV201206.shtml)

与PB相比，2020年差24秒，2023年差13秒，2026年差38秒。把这些差值写出来，会看到一种被“有没有PB”遮住的表现：不同年份里，她曾多次接近自己的最高水平。它不意味着每一季都同样顺利，也不能证明所有训练安排都正确，但说明她的竞技履历没有在旧纪录写下之后停止。[S1](https://worldathletics.org/athletes/pr-of-china/zhixuan-li-14376349)

她更早如何进入专业训练，本次没有获得足够完整的本人采访。2018年中新网现场报道已明确她是一名专业田径运动员，也记录了她对全马方向的选择。本文从这个可核实的选择谈起，不用出生地或赛地猜测成长经历。[S4](https://sports.cctv.com/2018/12/02/ARTIBcsO1ODXpCIuYcIM6haI181202.shtml)

## 把东京这场比赛放大一点

2026年东京的2小时26分53秒，平均配速约为每公里3分29秒。38秒分摊到42.195公里，约是每公里0.9秒。这个差值让“接近PB”有了可以理解的尺度：不是几分钟以上的距离，而是一整场极细的平均速度差。[S1](https://worldathletics.org/athletes/pr-of-china/zhixuan-li-14376349)

然而，接近并不等于只差一次冲刺。本文未取得李芷萱这场比赛完整官方分段，也没有核实她经过各个补给点的情况，因此不能说她把最后一公里跑快一点就能改写PB。总时间相近的两场比赛，过程完全可能不同；平均配速只说明结果，不说明身体如何分配能量。

她在东京获得第13名，也不宜直接改写为“中国女子第13”或某种综合实力排序。世界田联个人资料收录的是该场总名次。PB榜则按个人最快合法全马成绩排列，目的与一场比赛的名次不同。[S1](https://worldathletics.org/athletes/pr-of-china/zhixuan-li-14376349)

## 更大的舞台，也会换一把尺子

2022年俄勒冈世锦赛，李芷萱以2小时31分20秒获得第22名，张德顺2小时28分11秒列第11名。世锦赛的结果给她的履历增加了国际大赛中的实际坐标。[S2](https://sports.cctv.com/2022/07/19/ARTIutVZHpCixwUycyqPpkxn220719.shtml)

2023年名古屋2小时26分28秒，比那届世锦赛快4分52秒。这个时间差是可核对的，原因却需要更多过程材料才能解释。对手构成、比赛目标、天气、路线及临场状况都可能影响结果；没有逐项证据，就不应把世锦赛较慢的成绩归结成某种心理弱点。[S1](https://worldathletics.org/athletes/pr-of-china/zhixuan-li-14376349)[S2](https://sports.cctv.com/2022/07/19/ARTIutVZHpCixwUycyqPpkxn220719.shtml)[S3](https://sports.cctv.com/2023/03/13/ARTIj0WhDe31ghzVSKKVU3Hs230313.shtml)

李芷萱自己的公开训练表述，在2018年的短距离比赛后已经相当明确：10公里服务全马目标。这个方向有原始采访支撑，但不能被延伸成一份从2018年持续到今天、细节不变的训练计划。她是否在某年增加跑量、改变强度比例，本次材料不能回答。[S4](https://sports.cctv.com/2018/12/02/ARTIBcsO1ODXpCIuYcIM6haI181202.shtml)

## 对一个长期跑步的人，38秒意味着什么

李芷萱的故事适合留给那些已经拥有一个旧PB、之后几年却总差一点的人。她的例子首先让人看见，纪录之外还有另一类证据：距离旧纪录多远，在多少个年份仍能接近它，又在哪种比赛中完成了其他任务。

普通跑者可以在自己的记录里增加一列“距PB差值”，并同时写明当场目标与条件。这是一种基于她成绩的复盘启发，不是借她的名字推荐具体训练量。没有PB的比赛，仍可以帮助识别节奏、耐力与恢复中的变化。

当然，长期接近纪录也不自动保证下一场突破。她最近一次东京成绩与旧PB之间的38秒，属于已经发生的事实；下一次能否追回，要等下一张真实成绩单。

回到2018年的上海，李芷萱在一场10公里胜利后谈起全马，那个清楚的方向比一句泛泛的坚持更容易被记住。多年以后，她仍在距离个人最好成绩很近的地方参赛。这段履历的重量，既在2小时26分15秒，也在旁边那些不断接近它的数字里。
