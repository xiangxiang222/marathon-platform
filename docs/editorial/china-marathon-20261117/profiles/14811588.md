# 苏飞：首尔之后七天，又站上武汉起跑线

赛历里的一周间隔，是值得研究的事实，也是不能随意模仿的边界。

2026年3月15日，苏飞在首尔马拉松以2小时10分06秒获得第十六名，刷新全马个人最佳。七天之后，3月22日，他在武汉马拉松以2:16:08获得第七名。一周、两场全马，这组记录把一个具体问题摆到读者面前：同一名选手在如此接近的比赛中，分别承担了怎样的任务？[S1](https://worldathletics.org/athletes/pr-of-china/fei-su-14811588)

## 能确认的变化

世界田联收录的全马年度最佳，从2024年上海2:12:12，到2025年无锡2:12:41，再到2026年首尔2:10:06。与此前最快的上海记录相比，首尔快2分06秒；与上一年度最佳比较，则快2分35秒。这两个差值对应不同的参照，不应混写。[S1](https://worldathletics.org/athletes/pr-of-china/fei-su-14811588)

2:10:06的平均配速约为每公里3分05秒。这个数字说明最终兑现的速度，却没有告诉我们首尔是前快后慢，还是最后阶段提速。没有分段表，就不能把一次PB写成某种战术教科书。

## 那一周，不宜替他解释

武汉比首尔慢6分02秒，名次却从第十六变成第七。它首先表明，比较比赛需要同时交代对手与赛事。我们尚未核实两场天气、路线和比赛任务，也没有本人对连续参赛的说明，因此不能说他在武汉“带着疲劳坚持”，或断言这是一次计划中的训练赛。[S1](https://worldathletics.org/athletes/pr-of-china/fei-su-14811588)

这条赛历也不构成对普通跑者的参赛建议。精英选手的支持条件、恢复安排与竞赛目标不同，读者不能把一周两场全马从人物档案里摘出来当作可复制方案。可以学习的是，看到反常识的记录后先提出问题，再寻找证据。

## 跑道与公路，都在他的赛季里

2026年7月全国田径大奖赛总决赛，苏飞在5000米以14:40.31获第一，10000米以31:54.65获第一；10月北京全马则为2:15:10。更短距离上的名次记录和全马PB，呈现的是同一赛季的不同面向。它们无法单独证明某种训练方法，却能提醒我们，选手并不只在一个距离里工作。[S1](https://worldathletics.org/athletes/pr-of-china/fei-su-14811588)

苏飞值得记住的，是这份具体而有悬念的赛历。首尔的突破已经有秒表作证，一周后武汉的选择仍需要本人解释。好的档案不必把所有空白填满：让问题保持准确，下一次采访和下一场比赛，才有机会真正为故事增加内容。
