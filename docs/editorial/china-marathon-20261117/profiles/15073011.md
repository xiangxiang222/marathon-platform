# 谢运策：从春天到秋天，少用六十二秒

同一赛季的两次全马PB刻度，让北京的突破有了近处的参照。

2026年10月18日，北京马拉松，谢运策以2小时09分47秒获得第七。翻到同年3月22日无锡的成绩，他跑了2:10:49、第十四。春天到秋天，终点时间缩短62秒，名次也发生变化；这为北京这次PB提供了一个比遥远履历更近的参照。[S1](https://worldathletics.org/athletes/pr-of-china/yunce-xie-15073011)

## 北京，曾经也是另一个起点

世界田联目前收录的2024年全马年度最佳，是11月3日北京的2:15:19；2025年衡水湖的全国马拉松锦标赛为2:12:58；2026年北京则来到2:09:47。两年间，公开年度最佳缩短5分32秒。我们不能把2024年北京称为他的第一场马拉松，却可以说，北京在这条已收录的进步线中两度成为刻度。[S1](https://worldathletics.org/athletes/pr-of-china/yunce-xie-15073011)

从2:12:58到2:09:47，最近一个赛季的年度最佳又缩短3分11秒；其中，无锡2:10:49已经先向前走了一段。这样的拆读比只写“进步巨大”更具体：读者知道突破来自哪一年、哪一场，以及与哪个旧成绩比较。

## 六十二秒意味着多大的差别

2:09:47对应全程平均每公里约3分05秒。把无锡和北京的差值摊到42.195公里，大约是每公里1.5秒。这有助于理解长距离比赛的累积效应，却不能当成两场逐公里配速的对照。北京与无锡的气象、路线、对手和补给安排尚未在本稿中完成核验，因此无法把这62秒单独归因于某一种战术。

北京同场，蒋发坤2:09:29列第六，比谢运策快18秒。成绩表提供一个清晰的竞争坐标，但没有证明两人全程同组，或者在最后阶段彼此发动攻击。场景应当停在已知的终点，不把缺失过程写成戏剧。[S1](https://worldathletics.org/athletes/pr-of-china/yunce-xie-15073011)[S2](https://worldathletics.org/athletes/pr-of-china/fakun-jiang-14839796)

## 中间那场比赛也需要保留

2026年5月31日吉林，谢运策以2:16:34获得第四。这场时间慢于春秋两次成绩，却依然是他赛季的一部分。只保留PB会让职业生涯看起来永远向上；把其他比赛留下，读者才有机会认识一次峰值出现前后的真实分布。[S1](https://worldathletics.org/athletes/pr-of-china/yunce-xie-15073011)

谢运策给普通跑者的启发，是把复盘的问题问细：相较同年春季，我改变了多少？相较上一年，我走到了哪里？哪些条件还没有比较清楚？这些问题不依赖虚构的励志经历，也无需照搬精英训练。至于他的成长、教练与训练变化，等待更多可靠采访后再写，才能让下一次更新真正增加理解。
