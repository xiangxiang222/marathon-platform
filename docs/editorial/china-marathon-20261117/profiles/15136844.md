# 扎西次仁：每一年，再往两小时十分以内走一步

从2:12:17到2:09:43，三年成绩留下清晰的进阶刻度。

2026年3月22日，无锡马拉松，扎西次仁跑出2小时09分43秒，获得第九名。对照此前两年世界田联收录的年度最佳，这个终点有一条清楚的来路：2024年无锡2:12:17，2025年大阪2:10:47。先快90秒，再快64秒，两年共缩短2分34秒。[S1](https://worldathletics.org/athletes/pr-of-china/ciren-zhaxi-15136844)

## 一条简洁，却不应过度解释的成绩线

三次年度最佳让他的档案有了鲜明的主题：持续向前的全马刻度。但“连续三年进步”不等于已经掌握了未来必定进步的公式。官方资料中的最早年度最佳也不能自动被称为首马；这里缺少的是入行经历与本人对成长阶段的讲述。

2025年大阪到2026年无锡，2:10:47与2:09:43之间只有64秒，却跨过了2小时10分这个便于公众记忆的门槛。门槛是数字的表达方式，真正发生的竞技工作，是把每公里平均输出再提高一点，并把它维持到全程结束。2:09:43对应平均每公里约3分04秒。

## 终点前后的参照

## 不只保留最好的一次

2026年3月仁寿半马1:02:39、第九；8月全国锦标赛10000米30:02.97、第十，这些是全马之外的官方参赛记录。它们丰富了赛季画像，却没有直接告诉我们训练量、技术动作或恢复安排。有关这些问题，本稿不以常识代替本人证词。[S1](https://worldathletics.org/athletes/pr-of-china/ciren-zhaxi-15136844)

普通跑者可以从他的成绩线中学到的，是用连续赛季检查长期变化，同时给单场波动留下解释空间。若自己的目标是破某个整分门槛，可以把它拆成可理解的平均速度，但不能把平均速度误当作已经具备的全程稳定性。扎西次仁这三年的结果，值得记住的正是每一次实际完成的进步，而不是编辑替他承诺的下一次。
