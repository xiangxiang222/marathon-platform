# 魏亚楠：最快的自己在首尔，新的成绩单在哈尔滨

2007年首尔2小时23分12秒，2026年哈尔滨2小时46分33秒。把这两个年份放在一起，魏亚楠的故事谈的不只是速度，也谈一个人怎样仍然出现在正式赛道上。

2026年9月13日，哈尔滨马拉松女子成绩中，世界田联为魏亚楠登记了2小时46分33秒、第10名。她生于1981年12月6日，完成这场比赛时44岁。[S1](https://worldathletics.org/athletes/pr-of-china/yanan-wei-14264959)

如果只看这一场，读者会看见一位能以平均每公里约3分57秒跑完全马的选手。再打开她的个人纪录，同一页上写着2007年首尔的2小时23分12秒。两场比赛相隔十九年，正式记录把两个时期的她放到了同一份档案里。[S1](https://worldathletics.org/athletes/pr-of-china/yanan-wei-14264959)

## 她曾跑到怎样的位置

世界田联收录的早期全马年度最佳，从2000年北京的2小时26分34秒开始。2001年北京2小时24分02秒，2007年3月18日首尔2小时23分12秒，成为她的全马PB。央视对北京马拉松历史的回顾，也将魏亚楠列在曾夺得女子冠军的中国长跑选手之中，中文姓名与国际资料形成交叉。[S1](https://worldathletics.org/athletes/pr-of-china/yanan-wei-14264959)[S2](https://sports.cctv.com/2018/09/14/ARTIcUmnbExkFGSOxh7nqyli180914.shtml)

她在2001年波士顿马拉松以2小时29分52秒获得第八名；同年10000米跑出31分54秒86，5000米15分15秒75。她的早期竞技经历同时跨越场地与公路，不是一条只由某一场马拉松构成的成绩线。[S1](https://worldathletics.org/athletes/pr-of-china/yanan-wei-14264959)

对于首尔PB，能够明确分析的是结果尺度：2小时23分12秒相当于全程平均每公里约3分24秒。本次未取得她当年的完整官方分段与可靠赛况，不为那场比赛安排未经证实的中途追赶，也不推测某一种训练方法造就纪录。[S1](https://worldathletics.org/athletes/pr-of-china/yanan-wei-14264959)

## 记录的间隔，不是可以随意填补的生涯

官方资料在2012年之后，下一条全马年度最佳出现在2023年吉林，2小时46分45秒；2025年长春2小时57分04秒，随后是2026年哈尔滨2小时46分33秒。资料表中存在长时间间隔，不能据此认定她在这段时间里完全没有跑步或没有参加任何其他赛事。[S1](https://worldathletics.org/athletes/pr-of-china/yanan-wei-14264959)

同样，本文没有可靠材料确定她退出专业队的日期、之后的工作安排或当前报名的专业与大众类别。这里保留能够核实的身份边界：她的世界田联本人资料下，近24个月仍有正式比赛结果。专题采用这个参赛标准将她纳入，不表示她仍在国家队或专业队承担备战任务。

2026年哈尔滨比她2023年吉林快12秒，比2025年长春快10分31秒。它们只是三个不同年份的比赛结果，不足以证明她执行了某个特定的“复出计划”。她怎样安排训练、怀着什么目标站上起点，仍应等待本人采访，而非由作者替她宣布。[S1](https://worldathletics.org/athletes/pr-of-china/yanan-wei-14264959)

## 当PB不再是每次起跑的唯一任务

魏亚楠在PB排序中靠前，是因为2小时23分12秒这项历史最好成绩；她最近的比赛表现则应看2026年的正式结果。把两者放开阅读，才能同时尊重她曾达到的竞技高度与现在的真实速度。

对普通跑者，这份档案提供一种可用的复盘尺度：在不同人生阶段，分别记录当年的目标、能够投入的时间和正式成绩。旧PB可以保留，但不必让每一次起跑都背负复制它的任务。这是作者从记录中提出的阅读建议，并非魏亚楠本人公开的训练主张。

十九年间速度变了，比赛仍在发生。记住她，可以同时记住首尔的2小时23分12秒，也记住哈尔滨那张新的成绩单。前一个数字属于已经跑到的高处，后一个数字说明这份档案还没有只剩历史。
