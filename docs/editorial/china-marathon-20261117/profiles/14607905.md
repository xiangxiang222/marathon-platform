# 李丹：把一次接近PB的回归看清楚

2024年距离旧PB仅33秒，怎样重新读李丹的长跑履历？

## 无锡，距离旧纪录33秒
2024年3月24日，李丹在无锡跑出2:27:32。她的全马PB是2020年南京的2:26:59，两个成绩相差33秒。对一名已经经历多个赛季的选手，接近最好成绩本身就值得记录，不必等到破纪录才算出现故事。[S1](https://worldathletics.org/athletes/china/dan-li-14607905)

世界田联收录的年度全马成绩从2016年的重庆2:33:38延伸至今。这个时间序列说明她长期参加全马，却没有提供童年入行的完整经过。本文不会把最早登记的一场比赛称作她人生的首马。[S1](https://worldathletics.org/athletes/china/dan-li-14607905)

## 2019年的两个面向
2019年李丹在北京跑出2:29:20。同一年的多哈世锦赛，她未能完成女子马拉松；当时报道记录了高温高湿环境对多项公路项目的影响，也列出了她的退赛。群体性的天气背景有据可查，她个人退赛的具体身体原因仍需本人或队伍材料，不能用大环境代替诊断。[S1](https://worldathletics.org/athletes/china/dan-li-14607905)[S2](https://sports.cctv.com/2019/10/07/ARTIXhkBEicfs51ZDQ1fB6kd191007.shtml)

2020年的2:26:59，将2019年度最佳推进2分21秒。之后年度成绩起伏，到2024年重新接近PB。如此安排时间线，能看见一次高点、之后的变化和后来的回升，而不是把所有年份排成不断向上的阶梯。[S1](https://worldathletics.org/athletes/china/dan-li-14607905)

## 33秒能解释什么
33秒摊到42.195公里，平均每公里不足一秒。这个量级说明2024年全程用时接近她的历史最好水平；它不能证明两场赛道或比赛过程相当。未取得完整分段和两届气象实测，本文不评价哪次更具难度，也不把接近PB归因于某个未公开训练周期。[S1](https://worldathletics.org/athletes/china/dan-li-14607905)

2025年名古屋她跑出2:30:46，2026年北京为2:37:38。新近成绩离PB更远，是档案应当保留的事实。现有公开资料不足以说明波动来自伤病、目标改变还是其他因素。[S1](https://worldathletics.org/athletes/china/dan-li-14607905)

## 长期跑者需要多把尺
她的5000米PB为15:43.33，10000米PB为33:07.75，说明她在场地长跑也有正式积累。理解这些不同年份的成绩，仍需把它们放回各自赛季。[S1](https://worldathletics.org/athletes/china/dan-li-14607905)

普通跑者可以借用她这段履历中的参照办法：除了刷新PB，也记录重新接近旧水平的比赛；对状态波动先保存事实，再寻找原因。李丹的下一次比赛，值得关注的是表现能否形成持续回升，而非先替她写好一个已经发生的复出结局。
