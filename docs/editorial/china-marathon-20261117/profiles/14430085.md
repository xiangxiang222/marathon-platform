# 吴向东：巴黎那两段坡，改写了他对马拉松的理解

第40名与中国男子当时最快的奥运完赛时间同时成立。吴向东的巴黎故事，提醒我们别只用PB理解一条赛道。

## 他在终点谈到的，是最后五公里

2024年8月10日，巴黎奥运会男子马拉松，吴向东以2小时12分34秒获得第40名。那是他第一次参加奥运会，也是当时中国男子选手在奥运马拉松中的最好完赛时间。赛后接受澎湃新闻现场采访，他把注意力放在后五公里的掉速，以及约28公里处让自己印象很深的爬升。[S2](https://www.thepaper.cn/newsDetail_forward_28372261)

这里有一个必须分清的细节：最好用时并不等于最好名次。同一篇报道记载，杨绍辉在东京奥运会获得第19名。奥运会每届路线、天气与比赛进程都不同，吴向东的时间突破有其价值，却不能被写成中国男子奥运马拉松历史最高排名。[S2](https://www.thepaper.cn/newsDetail_forward_28372261)

## 坡度总量之外，还有坡度分布

吴向东在采访中解释，备战已经安排爬升训练，但平时坡度分布较散，巴黎赛道的爬升却集中在两个部分。这个区别比一句赛道很难更具体：相同类型的能力，在不同的组合方式下会面对不同负担。[S2](https://www.thepaper.cn/newsDetail_forward_28372261)

这是他的赛后经验，不是一份训练实验。本文没有取得吴向东训练路线的海拔曲线，也未复核他的全程逐点分段，因此不能量化集中爬升究竟让他慢了多少，或断言改哪一堂课就能避免掉速。可以提炼的比赛问题，是备赛时不仅看累计爬升，还要看坡出现的位置，以及它与后程疲劳怎样重叠。

奥运赛事也使PB与比赛表现之间的关系变得更清楚。吴向东2024年大阪的全马最佳为2小时08分04秒；巴黎的2小时12分34秒更慢，却是在不同路线和冠军赛竞争中完成的成绩。两场相差4分30秒，这个差值不能全部归因于路线，因为对手、天气、战术等变量也没有被控制。[S1](https://worldathletics.org/athletes/athlete=14430085)[S2](https://www.thepaper.cn/newsDetail_forward_28372261)

## 三十岁的第一次，并非生涯末尾

吴向东出生于1994年1月17日。世界田联年度最佳记录从2017年天津2小时22分54秒，经过2020年南京2小时12分50秒、2021年徐州2小时11分36秒，来到2023年无锡和北京两次2小时10分02秒。2024年大阪，他进一步跑到2小时08分04秒。[S1](https://worldathletics.org/athletes/athlete=14430085)

这个跨度让三十岁首次参加奥运会有了具体背景：那不是此前没有进步的空白十年，而是成绩逐层改变之后的一次大赛入口。巴黎赛后，他表达了希望继续参加下一届奥运会的愿望。愿望属于当时的他，我们不把它提前写成已经获得的资格。[S2](https://www.thepaper.cn/newsDetail_forward_28372261)

2025年的年度最佳2小时12分20秒，没有追平大阪PB；2026年9月27日柏林，他以2小时07分55秒获得第14名，把个人最佳再提高九秒。这九秒幅度不大，却说明年龄标签不足以替他判断成绩上限。它也不能反过来保证此后每个赛季都继续提高。[S1](https://worldathletics.org/athletes/athlete=14430085)

普通跑者阅读吴向东，最实用的动作是重新打开目标赛事的路线图：长坡在前半程还是后半程，爬升是零散分布还是集中出现，自己过去的训练覆盖了哪一种情形？答案比机械地复制PB配速更接近具体比赛。吴向东留给读者的鲜明细节，就是一位第一次来到奥运会的选手，在终点把一次宏大的经历拆回了两段需要重新理解的坡。
