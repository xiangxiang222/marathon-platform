# 孙腊梅：速度留下的底色，与十二年后的全马记录

她的个人纪录里有4分15秒06的1500米，也有2小时27分55秒的马拉松。多年之后，新的参赛记录提示我们：一位运动员的故事，不必在旧PB那一栏停止。

2012年11月25日北京马拉松，孙腊梅跑出2小时27分55秒。世界田联至今将其登记为合法全马PB。十二年后，2024年12月22日汕头马拉松，同一人物编号下又出现一场全马出赛记录：3小时03分45秒，第八名。[S1](https://worldathletics.org/athletes/china/lamei-sun-14265279)

汕头这条记录附有UNC标记，积分为零。本文保留这一原始标记，仅将该场用于确认她近24个月内曾正式参赛，不据此建立或改写合法PB，也不擅自解释标记的具体原因。[S1](https://worldathletics.org/athletes/china/lamei-sun-14265279)

## 全马之前，她也曾跑得更短

孙腊梅生于1991年1月4日。世界田联个人纪录里，1500米是2009年长沙的4分15秒06，5000米是2010年济南的15分42秒01，10000米33分34秒82。2007年北京，她还跑出半程马拉松1小时12分59秒。[S1](https://worldathletics.org/athletes/china/lamei-sun-14265279)

这组事实让她的竞技底色更清楚：较短距离的速度与更长的公路跑，共同出现在履历中。不过，不能由成绩日期直接认定她在哪一年正式改项，也不能从个人纪录猜测教练怎样分配训练。

北京2小时27分55秒，折算全程平均配速约为每公里3分30秒。这个数字说明她曾达到的全马速度；没有完整分段与原始比赛报道，不能说她当时如何起跑、在哪一公里提速、怎样处理补给。[S1](https://worldathletics.org/athletes/china/lamei-sun-14265279)

## 记录出现的那一天

官方资料的近年比赛栏收录汕头出赛，但没有给出她当前的专业队身份、职业安排或参赛目标。因此，这份档案不替她宣布“职业复出”，也不根据比PB慢35分50秒的结果猜测伤病或训练状况。时间差可以计算，原因仍应由可靠材料解释。[S1](https://worldathletics.org/athletes/china/lamei-sun-14265279)

本专题采用近24个月正式参赛判断活动状态，PB排序则保留她历史认可的最好成绩。这两种信息需要一起阅读：它们分别回答“最近是否参赛”和“曾经最快跑过多少”，不能合成一句未经定义的当下实力判断。

普通跑者可以从孙腊梅的成绩结构中借用一个办法：把1500米、5000米、半马与全马各自保留，观察自己在哪种距离有过积累。不同项目提供不同角度，不能靠一项旧速度直接给今天的全马定目标。

关于她的成长、训练和多年间的调整，仍值得补充本人采访。现阶段能够准确交给读者的，是一位有场地速度记录、有全马2小时27分55秒，也在后来继续留下参赛记录的跑者。这个轮廓有边界，也有继续认识她的理由。
