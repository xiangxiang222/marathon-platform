# 数据来源页改版验收

## 页面与状态

- Web 和微信小程序使用同一套红白灰界面：正常导航标题、四品牌白卡、独立文件导入卡、两项折叠说明及隐私页尾。
- 移除本子页重复的大标题、跨档案横向标签、空白字母图标和默认展开的长说明；其他档案子页保留原有导航。
- 仅显示佳明 Garmin、高驰 COROS、华为运动健康、颂拓 Suunto，顺序两端一致。API 目录同步删除 Apple 健康。
- 四品牌始终为“待开通”。前端不提供授权或同步按钮，也不信任旧 API 返回的 connected/available 状态；后端继续拒绝尚未开通的连接与同步请求。
- 明确返回 `canDisconnect` 的旧连接可单独清理；确认操作绑定打开时的账号和页面，保留已保存运动。
- 品牌图标使用官方应用图标的小尺寸 PNG，来源见 `device-brand-assets-20261112.md`；每端新增资源总计 12,122 B。

## 文件导入

保留 FIT / TCX 单场运动、5 MB 限制及本次解析的单独同意。显示格式/大小校验、处理中、导入成功、重复记录、信息补全和失败后的恢复操作。

导入方法和数据规则默认折叠。小程序步骤保留微信“文件传输助手”；规则明确仅存运动摘要与去重信息、不留原文件/GPS/心率，按跑团手填规则计入 PK，不自动生成赛事成绩，重复冲突需核对已有运动。隐私政策及权限说明仍可访问。
