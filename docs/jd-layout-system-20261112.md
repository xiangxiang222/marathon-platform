# 全站页面结构与视觉规范

以赛事页现有清晰的搜索、日期卡与筛选为锚点，借鉴京东参考的信息分区、身份与状态摘要、白卡层级和紧凑服务入口。页面按赛事、个人、跑团、内容、活动、表单、作品与运营工作台分类适配。

- 主色 #ff1838；浅红 #fff0f2，底色 #f5f5f5，白色内容卡。主导航身份头浅红到近白、黑字，赛事保留红色搜索区。
- 页面边距16、卡片间距12、内距14–16、卡片圆角12；非输入卡片不依赖完整外边框区分。
- 字级24/18/15/14/12；一模块一个主指标28–36，其余18–24，单位12，零数据不做巨大数字墙。
- 角色类 ui-identity / ui-status-summary / ui-service-group / ui-content-card / ui-directory-row / ui-form-section 对应身份头、状态条、服务组、内容卡、名单行与表单段，两端同义。
- 真实头像、Logo、比赛照片负责内容识别；主要功能入口保留原有立体彩色图标；搜索、返回、编辑等基础控件使用线性图标。图标本身的蓝绿金色细节保留，页面背景和主操作继续使用统一红白灰。图片缺失回退文字，不使用无关图片或固定虚假数字填充。
- 主操作44px，搜索按钮视觉56×34、命中44px；次操作用细边框或文字，同屏强调一个当前操作。

基础批次调整共享头部、工具图标、赛事首页内容入口与拿奖雷达。业务页面同时调整了模板结构：个人数据与近期事项、跑团安排与名单、人物入口与长文、活动状态与操作、表单填写任务各自分区。页面内部标签、长文本、空态、错误态均纳入检查；原生编译和源码镜像不代替微信真机发布。
