# 北马专题设计稿 · 原创视觉

本目录全部为本项目以 SVG 代码原创绘制的设计资产。没有使用网络下载图片，没有调用图片生成 API，没有临摹官方标识。

| 文件 | 设计用途 | 展示说明 |
| --- | --- | --- |
| `beijing-cover.svg` | 北京晨光、城市地标与跑者的宽幅专题封面 | 原创插画，非北马实拍，非某届赛事现场 |
| `jersey-study.svg` | 参赛服图鉴的构图、比例与配色示意 | 原创概念服装，非任何年份的真实参赛服 |
| `medal-study.svg` | 奖牌图鉴的材质、细节与版式示意 | 原创概念奖牌，非任何年份的真实完赛奖牌 |
| `gallery-study.svg` | 相册封面的城市跑步场景示意 | 原创插画，非官方照片或历史影像 |

图片不包含官方 Logo、届次、年份和赛事文字。各文件 `<title>`、`<desc>` 均注明原创设计及示意性质。原生页面可以在图片之外加文字，示意资产不得进入真实年度物品或官图数据。

以前为本轮设计下载的 JPG、外部署名与来源记录已经删除。本目录仅用于可点击设计稿，不修改生产赛事页面。

视觉色板：品牌红、酒红、炭灰和浅暖灰。封面采用暗红曙光与朱红城墙，奖牌仅保留局部金属金色；不使用绿色、青色或蓝绿色。
