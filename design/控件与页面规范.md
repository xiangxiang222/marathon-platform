# 赛历 · 控件与页面规范

2026-11-11 根据小象超市参考进一步调整：大面积白色内容卡、浅灰页面底，顶部保留局部浅色渐变，色彩集中在图标、状态、模板和少量重点内容。沿用原有红色主操作，配合薄荷、天空蓝、杏金和柔紫。页面的清爽感来自留白、对齐、清楚的文字与稳定的层级。

## 基础色板

| 用途 | 色值 | 使用方式 |
| --- | --- | --- |
| 页面底色 | `#f5f6f8` | 中性浅灰，承托白色内容；顶部浅彩过渡在约 240–360px 内结束 |
| 内容表面 | `#ffffff` | 卡片、表单、弹层 |
| 主文字 | `#262626` | 标题、正文、数据 |
| 次文字 | `#737373` | 解释、元信息、字段说明 |
| 分隔线与边框 | `#eaedf1` | 1px 细线，不用粗描边 |
| 主操作与强调 | `#e1251b` | 发布、提交、保存、当前焦点 |
| 浅色强调底 | `#fff2f0` | 选项选中及少量提示 |
| 输入背景 | `#f8faff` | 与白色容器形成轻微区分 |
| 薄荷浅底 / 深字 | `#e9f7f2` / `#23765f` | 运动、参与、完成状态、小图标 |
| 天空蓝浅底 / 深字 | `#eaf4ff` / `#2767aa` | 日期、跑量、信息入口 |
| 杏金浅底 / 深字 | `#fff4d7` / `#986614` | 里程目标、长距离模板、纪念权益 |
| 柔紫浅底 / 深字 | `#f2edff` / `#7753ae` | 个人档案、跑史、雷达入口 |
| 桃色浅底 | `#fff0e7` | 活动与赛事顶部的局部氛围 |
| 禁用背景 / 文字 | `#f2f2f2` / `#999999` | 保留可读性，避免整块淡到看不见 |

辅助色表达内容语义、状态和数据系列，使用位置保持稳定。大段正文、连续列表、普通表单和数据面板保持白底。一个标题区采用一种辅助色向白色过渡；彩色入口使用小图形或小底块，主体保持干净。主按钮保持红色，列表的日期与状态可以使用对应的浅色。照片和头像保留本来的颜色。

## 字体与间距

使用系统字体：`-apple-system, BlinkMacSystemFont, PingFang SC, Helvetica Neue, Microsoft YaHei, sans-serif`。保持中英文在同一设备上协调，不引入网络字体。正文优先 14–15px、行高 1.65–1.8；表单输入 14px；区块标题 17–20px；页面标题 24–26px。标签和解释 12–13px，11px 只用于较短的辅助刻度或元信息。移动端不能随 rpx 无限缩小。

标题使用 600 字重，主操作 500–600；正文和说明使用 400。数量与时间采用等宽数字。避免把每行文字都加粗。小程序主要页面通过共用 `page-header` 避让真实状态栏与胶囊，不绘制虚假设备状态栏。

常用间距按 4px 递增。页面左右留白 16px，窄屏最少 14px；卡片内边距 16–20px；字段之间 16–20px；独立内容区之间 24px。用对齐和留白组织内容，不为每一个字段加独立大卡片。

## 控件

| 控件 | 形态 | 交互与使用 |
| --- | --- | --- |
| 主按钮 | 高度 44–48px，12px 圆角，红底白字 | 每个操作区保留一个主要动作；加载时阻止重复提交 |
| 次按钮 | 同高，12px 圆角，白底细灰边 | 返回、取消、编辑；与主操作明确区分 |
| 文字操作 | 透明底，紧凑文字或细线图标 | 分享、展开、查看；视觉紧凑但保持可点区域 |
| 筛选与分类 | 8px 圆角，细边框，12–13px | 选中用浅色背景与明确文字；不使用厚重大胶囊 |
| 状态标签 | 6px 圆角，11–12px，较小内边距 | 信息展示，不伪装成可点的大按钮 |
| 页签 | 文字与短下划线 | 选中强调字色和线条；避免再套一层大白胶囊 |
| 输入框 / 选择器 | 最小 46px，10–12px 圆角，轻底色和细边 | 字段名独立在上，单位与可选说明放次级位置 |
| 文本域 | 同输入语言，正文 14px，行高 1.75 | 保留适当编辑高度，长文不塞入单行输入 |
| 开关 | 原生控件，小范围独立成行 | 不挤在多列表单的左侧占输入宽度 |
| 卡片 | 18px 圆角、白底、细边 | 极轻阴影或无阴影；层级主要靠留白与标题 |
| 弹层 | 白色表面，顶部 20px 圆角，明确标题 | 主要动作与关闭操作分开，输入可见，保留安全区 |
| 提示与错误 | 短文字、轻背景、小图标 | 显示可采取的操作；接口错误不向用户输出 HTML |

圆形仅用于头像、图标按钮和确有含义的进度点。底部固定操作区有安全区留白，并为正文预留完整滚动空间。分组、表单和多按钮区域在 320px 下不得横向溢出或将四字操作挤成两行。

## 页面组织

- 赛事列表：搜索、分类、筛选、列表按层级排列；日期与赛事名称明确，少量状态强调。
- 跑团与个人中心：标题身份、重点信息、常用入口、更多功能；避免每个入口使用不同的按钮语言。
- 活动详情：小型类型与状态标签、紧凑分享、标题与里程摘要、正文页签、信息列表、独立管理区。
- 发布与编辑：必要信息先显示，可选设置折叠；分组字段整齐排布；草稿提示不会挤压文字。
- 训练模板：保存、编辑模板与发布活动分别操作；日期与期次按每场确认。
- 数据与榜单：数字优先，单位和解释次级；不同统计系列使用稳定颜色。
- 文章、法律与帮助：阅读宽度、正文行高和段落间距优先，不强行堆叠操作控件。
- 后台：同一色板、字号和按钮层级；表格在自身容器内滚动，工具栏按屏幕宽度换行。

## 代码与验收入口

小程序基础定义在 `miniprogram/app.wxss`，共用详情在 `miniprogram/utils/club-detail.wxss`；页面只补自身布局与控件角色。Web 使用 `web/src/styles.css`、`web/src/styles/consumer.css` 和后台样式，局部规则遵守同一色板及尺寸。

导航图标使用统一线性 SVG，功能入口结合轻填色与圆形浅底，形成鲜明但紧凑的彩色图标。两端入口共用源码，微信所需透明 PNG 由 `node scripts/sync-ui-icons.cjs` 生成。分享长图保持相同文字与品牌色。

`node scripts/ui-system-audit.cjs` 运行隔离 Web、后台和小程序镜像验收；支持 `web`、`admin`、`mini` 参数分开执行。最新清爽配色资料在 `design/previews/colorful-ui-20261111/`；`bright-ui-20261111/` 保留为本轮前的红白浅灰参考。浏览器截图和小程序源码镜像不能替代微信真机验收，报告应明确其来源。
