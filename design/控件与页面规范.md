主入口共享红色顶部、白色标题与操作，首张身份或数据卡衔接顶部下缘。搜索框白底；内容列表以黑灰信息为主，红色表达操作和选中。二级阅读、详情、表单使用白色导航。照片、头像、用户生成的海报样稿及确有语义的审核状态保留必要色彩。普通跑量、训练组、服务入口和表单不各自建立绿、蓝、紫、金主题。

## 字体和尺寸

使用系统黑体栈：`-apple-system, BlinkMacSystemFont, PingFang SC, Helvetica Neue, Microsoft YaHei, sans-serif`。中文自然字距，字重正文400、操作500、标题600。

| 角色 | 字号 |
| --- | --- |
| 辅助信息与时间 | 最小12px |
| 正文、输入、主次按钮 | 14px |
| 列表标题 | 16px |
| 分区标题 | 18px |
| 页面标题 | 24px |
| 重点跑量数据 | 36–40px |

移动端字号使用px下限，不因320px屏宽按rpx缩成10px。数据采用等宽数字。正文行高1.5–1.75，长文适当增加；避免大标题、过粗数据、英文口号占据首屏。

## 控件和布局

- 卡片12px圆角，白底、细灰边、无重阴影。主页面左右12px，卡片内16–20px。
- 主按钮品牌红底白字；次按钮白底灰边；同一操作区保留一个主动作。高度44–48px、控件圆角10px。
- 输入、日期、选择器采用同一浅灰底、14px字号、44px以上触达区域；标签独立显示，错误紧跟字段。
- 页签使用文字与短红下划线，主次导航保持同一语言。选项使用浅红和红色边框，不使用大面积深色块。
- 展开、收起、管理入口使用通栏透明行；文字与箭头左右对齐，显式清除原生button边框，保持至少44px触达区域。
- 弹层白底、明确标题、统一输入和底部主次动作；保留安全区。弹层和卡片不再重复套白色大按钮容器。
- 页面底栏固定时为正文保留滚动空间。320px下字段可改单列，表格在自身容器滚动，页面不横溢出。

## 关键页面行为

四个主入口统一为「赛事 / 跑团 / 运动 / 我的」。赛事首页保留搜索、分类、四个工具入口与筛选。跑团首页先给已加入跑团，再提供搜索与创建。运动先展示本月跑量，再提供记录和文件导入。我的先展示身份与摘要，再给赛事、跑史、数据与设置。

退出登录位于我的右上角设置中；海报入口随个人完赛/PB内容呈现。赛事分享到跑团采用一次展开、选择跑团和一个主要分享动作，避免每个跑团重复完整赛事大卡。资讯入口保留在赛事工具区，运动员、私兔、行业和跑团内容共享资讯中心；详情与发布表单沿用同一规范。
