字体使用系统字体栈：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", "Microsoft YaHei", sans-serif`。不加载远程字体。同一设备优先使用同一系统字体。

Web 常规正文 15px、说明 12–13px、区块标题 18px、页面标题 24–28px。小程序按 750rpx 画布适配，常规正文 30rpx、说明 24–26rpx、区块标题 36rpx；四个主页面采用共享自定义标题组件，二级页面保留原生导航。避免为对齐截图而绘制虚假的状态栏。

卡片圆角 Web 16px / 小程序 32rpx，输入框圆角 12px / 24rpx，主操作采用胶囊圆角。主要操作与表单输入的触控高度至少 44px。卡片使用平面白底，仅页头和重点摘要使用很浅的暖红渐变，列表保持平面。主操作为红底白字，次操作为白底灰边框，禁用态为灰底灰字。详情页面导航与登录切换使用红字及红下划线，筛选项使用浅红底及红字。

底部导航使用统一的 24×24 线性图形、圆端点和圆连接，普通状态深灰色、选中状态红色。底部导航的 SVG 原稿位于 `web/src/assets/navigation/`，小程序 `miniprogram/images/*[-on].png` 来自同一 SVG，以透明底 72×72 像素导出。修改图形时需要同步两端资产。首页日历、雷达、跑团和资讯入口使用原创彩色矢量图形，SVG 位于 `web/src/assets/quick/`，对应小程序 `miniprogram/images/quick-*.png`；分类入口使用文字标签，不使用图标方块。

Web 全局样式入口为 `web/src/styles.css`，页面只补充结构所需的局部样式，颜色引用 CSS 变量。小程序全局入口为 `miniprogram/app.wxss`，各页面 WXSS 使用上表同一组色值，原生二级导航及底栏颜色由 `app.json` 指定。

程序生成的日历长图、赛事占位图与分享卡片沿用此规范。日历长图已确定使用浅灰背景、白卡、红色日期和黑灰文字；两端 `day-poster.js` 绘制逻辑保持一致，保留长列表自动换行和自动高度。长图不展示报名状态，不放占位码；预览保留长按保存提示，不增加保存或关闭按钮，点击遮罩空白关闭。

验证覆盖 Web 移动端 320px / 390px、跑团五个页签、个人资料、入团登录和审核申请；小程序使用微信原生 WXML/WXSS 离线编译检查全部页面。微信原生组件和不同操作系统的字体光栅化存在平台差异，最终尺寸和交互仍以开发者工具及真机为准。

## 跑团详情页细化

跑团详情页于 2026-11-10 进一步细化：背景采用暖灰 `#f6f5f3`，白色名片配红色方章和浅色跑道线条；团名使用 24–27px，元数据保持至少 12px。下一次活动为空时使用浅杏底及独立红色发布按钮，快捷入口统一为细线图标；待参加、会费与签到收在同一白色区域。小程序图标原稿和透明 PNG 位于 `miniprogram/images/club/`；该页使用局部样式，不改全站色板。预览和验证见 [跑团详情页细化](previews/club-polish-20261110/README.md)。

## 首页布局

首页按「标题与日期 → 搜索 → 赛事分类 → 四个功能入口 → 单条截止提醒 → 赛事标题与筛选 → 赛事列表」排列。取消独立日期行、125px 提醒大卡和大面积彩色日期块。

小程序首页使用 custom navigation，状态栏高度和胶囊避让按微信系统 API 获取，标题与日期并排；滚动时只固定导航部分。顶部从浅粉过渡到白底，正文为浅灰底白卡。Web 沿用同一布局，省去原生状态栏和胶囊占位。

赛事浏览提供「路跑 / 越野赛 / 线上赛 / 线下赛」四个入口，附类型与参赛方式说明；它们不是四个互斥类别。缺少可靠国家字段时不展示海外入口。

赛事卡片使用浅红日期块、红色日期、16px / 32rpx 的黑色赛事名称，城市和项目为单行灰色说明，报名状态与截止时间在底部并排。仅报名开放、比赛中和临近截止的提示强调红色，未公布等状态为灰色。长标题最多两行；日期本身不表达报名状态。

小程序宽度不超过350px时，赛事标题至少15px、辅助信息至少12px、状态至少12px，避免全部按rpx缩小导致难读。保持24px首页标题和胶囊避让，赛事列表不横向溢出。

本次校验包括两端首页搜索、类型与参赛方式四入口切换、筛选、四个工具入口、详情跳转、提醒轮播，以及320px和390px的首屏与导航遮挡。微信开发者工具自动化服务端口关闭，采用微信原生离线编译和源码浏览器布局镜像检查；镜像不代表真机截图。

## 页面结构与交互

本轮页面分工、信息顺序、折叠操作和能力边界以 [产品与 UI 改版方案](产品与UI改版方案.md) 为准。底部导航统一为「赛事 / 跑团 / 运动 / 我的」。主页面共享 `page-header` / `PageHeader`，小程序读取真实状态栏与胶囊尺寸；页面内容不绘制设备状态栏。
