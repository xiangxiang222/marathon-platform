# 赛历 · 原创小插画

2026-11-11。按用户“自己设计一些小的图片”的反馈，主入口采用项目内原创小插画。当前页面不使用本轮调研时下载的通用摄影素材。

## 图片与位置

| 图案 | 页面用途 |
| --- | --- |
| 日历 | 赛事日历快捷入口、比赛计划卡 |
| 奖牌 | 拿奖雷达、运动员档案、个人完赛成绩 |
| 双人伙伴 | 跑团发现入口 |
| 资讯纸张 | 跑圈资讯入口 |
| 跑鞋 | 运动月报、私兔档案入口 |
| 跑者护照 | 我的身份卡、跑史入口 |
| 成绩海报 | 完赛信息附近的海报工具 |

图案采用一致的斜向视角、顶部高光、底部柔和投影和浅色底座。红色为品牌主色，金色、青绿、蓝色仅作为插画材质配色。页面正文保持黑灰层次；红色用于选择状态、主操作与数据进度。

常规入口图为48–58px，内容模块图为64–90px。图像不承担必读文字；标题、说明、按钮和数据仍是原生文字，以支持不同屏幕和真实内容长度。人物档案不配通用人像，避免错误对应真人。

## 可维护资源

生成源：[build-navigation-art.cjs](../scripts/assets/build-navigation-art.cjs)。使用 SVG 绘制，浏览器渲染透明 PNG；不调用图片生成服务或外部素材。执行 `node scripts/assets/build-navigation-art.cjs` 可重建资源。

Web 可编辑SVG与PNG位于 `web/public/images/art-*`；Web快捷入口SVG位于 `web/src/assets/quick/`；小程序透明PNG位于 `miniprogram/images/art-*` 与 `quick-*`。两端图片由同一生成源输出。

页面应用预览：[小程序四入口源码镜像](previews/jd-visual-v3-20261111/mini-contact.png)。小程序预览来自当前 WXML/WXSS 的浏览器镜像，非微信真机。
