# 小程序团友主页五页签专项验收

本目录使用实际小程序 Page JS、WXML 和 WXSS，配合内存合成响应完成验证。没有访问生产接口、修改数据库或写入业务数据。浏览器源码镜像用于检查排版，不等同微信真机操作；离线原生编译也不代表真机交互已经测试。

复现命令：`node design/previews/member-profile-20261111/run-mini.cjs`。

- `mini-vm-report.json`：39 项实际 Page JS / navigation 检查，覆盖五页签、全部空态、赛事状态筛选、本人介绍修改与失败重试、相册预览、跨年历史周期及未来限制、账号切换、请求乱序和隐藏后响应隔离、排行及成员名单链接、历史报表日期和导出参数。
- `native-report.json`：全部 48 份 JS、36 份 JSON、35 份 WXSS 严格语法检查，以及 32 份 WXML 的 `wcc`、35 份 WXSS 的 `wcsc -pc 35` 原生离线编译；严格解析同时覆盖缺分号探针，编译产物非空且无诊断。
- `mini-report.json`：22 个场景分别按 320 / 390 宽度生成，共 44 张完整源码镜像。检查表达式、事件处理器、页面横向溢出、图片加载、浏览器 console.error / pageerror。五页签含有数据/空态，另含加载失败、本人编辑、长昵称、三种赛事过滤、历史跑量，及历史周/月/年报和报表空态/失败。
- `mini/contact-five-tabs-320.png`、`mini/contact-five-tabs-390.png`：五页签对照；`mini/contact-reports-320.png`、`mini/contact-reports-390.png`：历史周/月/年报对照。`mini/*.html` 与对应完整 PNG 可逐页检查。
- `mini-source-manifest.json`：验收时相关产品源码的 SHA-256，方便识别后续修改是否需要重跑。

合成显示数据固定在北京时间 2027-01-01 00:30，专门覆盖跨年边界，历史报表锚点为 2026-12-15。每份有数据主页含 5 场赛事（完赛 2 场，中签、想跑、未中签各 1 场）、2 条成绩/PB、2 个活动相册共 4 张明确合成的跑步插画；这些数量是镜像 fixture 的显示口径，不是生产数据统计。赛事“想参加”仅包含想跑；未中签/弃赛及过去未确认参赛的标记只在“全部”显示。“待出发”要求今天或未来且可出发状态，“已参赛”要求今天或过去且有成绩/完赛/未完赛记录。相册只使用本团公开活动媒体合同，没有私人设备、凭证、轨迹或地址。

本专项没有重跑已通过的 284 项后端测试，也没有验证真实照片上传、真实微信视频播放、系统相册/日期选择器的真机表现。VM 验证的是原生调用参数和权限分支，源码镜像用浏览器近似原生控件。
