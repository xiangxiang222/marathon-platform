# 小程序源码渲染镜像

这些图片是浏览器根据当前 WXML、WXSS 与 Page 脚本生成的源码镜像，**不是微信模拟器或真机截图**。系统状态栏、胶囊和底栏由预览工具单独模拟。

`mini-races-public-*` 读取本地服务公开赛事、提醒接口；`mini-clubs-fixture-*`、`mini-sport-fixture-*`、`mini-mine-fixture-*` 使用内存中的示例账号、跑团与运动记录，不代表真实运营数据。预览没有向开发库发送写请求。

每页均有 390×844 与 320×760 两个尺寸。`mini-overview-*` 将四页排成带说明的总览图。对应 HTML 是浏览器渲染后的静态快照，供布局检查。字号、横向溢出、胶囊避让及展开表单检查见 `mini-source-mirror-report.json`。微信原生控件、字体细节和交互仍以开发者工具与真机为准。
