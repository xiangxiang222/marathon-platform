# 可复用训练模板：本地实现与验收

本目录记录 Web 与微信小程序训练发布页的模板功能预览。功能代码已在本地工作树实现；这些截图和报告不代表生产已部署。此轮验收使用隔离测试数据库或内存接口，没有访问生产业务数据。

## 如何使用

跑团团长、管理员从本跑团的发布训练入口进入。可以套用轻松跑、间歇跑、长距离内置安排，也可以套用本跑团共享模板，然后补充本次日期、时间、地点并发布。

在活动编辑中选择“存为模板”，填写名称后保存，当前活动内容和个人草稿仍保留。也可选择“新建模板”，只填写常用信息；此模式保存到模板库，不会发布活动。退出模板编辑会恢复进入前的活动内容。模板菜单支持编辑、删除；删除或修改模板不影响已经发布的活动。

模板在同一跑团的团长、管理员之间共享，每团最多 50 个，名称为 1–30 个字。普通成员、游客不能读取或维护模板。不同跑团的模板互相隔离。编辑带版本号，遇到别人先保存产生的冲突时返回 409，需重新载入后确认内容。

## 保存什么

| 类别 | 保留字段 |
| --- | --- |
| 训练内容 | 训练类型、默认活动标题、计划公里数、训练安排、参与须知、补充说明 |
| 地点 | 活动地点、具体集合点、集合时刻或说明、路线 |
| 报名分组 | 启用组别的名称、类型、配速说明、人数上限；0 表示不限 |
| 成团与积分设置 | 最少成团人数、积分里程门槛、活动积分、审核开关 |
| 常用时间 | 开始时刻 `HH:mm`、预计时长、报名提前截止分钟、取消提前截止分钟 |

默认活动标题留空时使用模板名称。地点可以留待每次发布补充。未提供分组时服务端补“全员组”；显式提交空分组数组会报错，避免模板套用后无法发布。

模板不保存本次活动的绝对开始/结束日期、报名/取消截止日期、期次、活动 ID、状态、报名成员、签到、成绩或相册。服务端拒绝配置白名单之外的键。模板记录本身仍有 ID、版本与创建/修改时间，这些仅用于管理模板。

从活动保存模板时，完整的结束/截止时间转换为相对于活动开始的分钟差。小程序套用模板时会保留本次已选日期；Web 套用模板后重新确认本次日期。时间按模板重算，跨天、跨年按北京时间处理。0 分钟保留原意，空值表示不预设；预计时长范围为 0–10080 整数分钟，提前截止范围为 0–43200 整数分钟。

个人草稿仍按账号与跑团存于当前设备；它保留本次日期，和共享模板分别保存。复制旧活动仍清空日期与期次，需要重新确认后发布。发布活动只走活动接口，保存模板只走模板接口。

## 本地验证

从仓库根目录执行：

```sh
node --test server/test/activity-templates.test.js
node design/previews/activity-template-mini-regression.cjs
node design/previews/activity-template-mini-mirror.cjs
```

Web 浏览器验收需要先运行本地 Web 开发服务，再执行下列脚本。默认预览地址为 `http://127.0.0.1:5174/marathon`，也可通过 `MARATHON_PREVIEW_URL` 指定本地服务地址。

```sh
node design/previews/activity-template-browser-regression.cjs
```

本次最终本地报告中，Mini 行为验收 18 组、源码镜像 14 个场景、Web 浏览器报告 23 项检查均通过；根目录 `npm test` 的后端 273 项测试通过。

后端测试主动使用隔离数据库，覆盖权限、跨团、CRUD、版本冲突、输入边界、绝对日期污染、删除模板不影响活动、删除跑团清理模板。Mini VM 与 Web 浏览器脚本使用内存接口，覆盖模板应用/保存/编辑/删除、草稿与复制、时间偏移、账号和跑团切换时的过期响应、普通成员不可操作等场景。非法分钟值（含 `NaN`）在确认保存、发请求前拦截；打开命名弹窗本身不写数据。具体结果以相应报告的 `passed` 和断言为准：

- [Mini 行为报告](mini-report.json)
- [Mini 源码镜像报告](mini-mirror-report.json) 与 [320/390px 镜像预览索引](mini-index.html)
- [Web 浏览器报告](browser-report.json)

Mini 镜像直接读取当前 WXML/WXSS，并使用实际 Page 处理器生成合成场景，检查 320px、390px 布局、按钮和事件绑定；截图中的选择器、输入框与原生控件由浏览器近似呈现。VM 与浏览器镜像不能代替微信开发者工具编译、原生交互或真机验收，也不能证明生产部署、真实账号或线上数据状态。未在本轮执行发布或线上写入。
