跑团详情：概览、活动状态与全部成员

白色资料区、浅灰页面与清晰的成员入口。正在进行与未来团练分别标示，过期、已结束、取消和无效时间不进入概览首卡。顶部头像与人数始终进入清空筛选后的全部成员。

本轮专项通过：Web 30 组；Mini Page VM 31 组；Mini 源码镜像 14 场景；严格样式解析及微信原生离线编译通过。所有业务 API 使用内存模拟，无线上读写。
