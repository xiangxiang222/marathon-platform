# 马拉松平台品牌概念 · 第二轮

面向全国跑者的一站式马拉松平台命名与 Logo 探索，包含选赛、报名、成绩、跑团与资讯的品牌应用。此目录是设计提案，尚未替换现有产品名称或图标。

用浏览器打开 [index.html](index.html)，可比较五组命名与图形，切换品牌应用、深色背景、单色和缩小效果，并下载 SVG。

源数据和矢量路径在 [create-concepts.cjs](create-concepts.cjs)，使用 Node 运行可重建全部 SVG 和离线预览页，无需额外依赖。中文组合使用系统字体；最终定稿仍需设计字标并将文字转曲。图形 SVG 使用内置配色及可编辑路径。

浏览器已验证五组切换和 SVG 下载、三种显示模式，以及 320 / 390 / 768 / 1440px 布局。PNG 对比稿、应用预览和透明字标位于本地 `design/previews/brand-concepts-20261115/`，按仓库规则不提交生成预览。

名字和图形均为创意候选，未完成商标、小程序名称及近似标志核验。应用商店关键词搜索只作为初步排查，不代表名称可注册。
