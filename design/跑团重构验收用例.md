# 跑团重构验收用例

适用：本轮跑团列表、团主页、活动/约跑/队内赛、成员与会费、相册、接龙与分享。结果以 [真实服务验收报告](./previews/club-live-acceptance-report.json) 的本次运行时间与计数为准。

本次稳定版验收于 `2026-10-30 03:00:27—03:02:34 UTC` 执行完成，进程退出码为 0：29 组真实接口场景、10 条真实浏览器点击旅程、15 个角色/视口组合下的 180 次页面访问全部通过。每项失败数均为 0；页面访问保存运行异常、宽度及截图证据。这些计数分别描述不同检查范围，不能相加当成测试用例总数。

## 环境与证据

- `node design/previews/club-live-acceptance.cjs` 会创建独立临时 SQLite 和媒体目录，启动本地 Express 和 Vite；结束后删除测试数据库与媒体文件。
- 五个账号通过真实注册接口创建：团长、跑团管理员、普通成员甲/乙、团外跑者；另外覆盖未登录游客。通过建团审核接口创建两个跑团，成员甲同时加入两团。
- 接口场景和浏览器点击均使用本地真实 HTTP；无 mock 代替业务返回。仅开始/截止时间边界在临时库调整时间，登录验证码从临时库读取；不修改现有业务数据库、不读取 `.env`、不向外部平台发请求。
- 报告分别记录 `api`、`browser`、`layoutGroups` 和 `layoutVisits`。布局扫描的每次访问保存角色、宽度、路径、页面异常、溢出宽度及截图文件名；布局检查不等同于完成该页面全部按钮交互。
- 截图文件位于 `design/previews/club-live-*.png`。网页视口为 320px、390px、1440px。桌面端沿用产品的移动端内容宽度。

| 编号 | 场景与预期 |
| --- | --- |
| AUTH-01 | 五账号注册成功，身份独立 |
| AUTH-02 | 错误密码拒绝；验证码密码登录回原账号 |
| CLUB-01 | 两团建团申请经过平台审批后创建 |
| CLUB-02 | 公开介绍不泄露成员、申请或口令；游客/团外不能读团内详情 |
| CLUB-03 | 拒绝后允许重新申请；审核通过后才能进入 |
| ROLE-01 | 团长可任命管理；成员不能创建组别；管理不能提自己/他人为团长 |
| GROUP-01 | 管理可建配速组与容量；负容量拒绝 |
| ACT-01 | 完整活动创建；非法日期拒绝 |
| ACT-02 | 有分组必须选组；两人并发抢最后一个名额仅成功一人 |
| ACT-03 | 取消释放名额；重复报名拒绝；团外不可报名 |

## 可复现命令

```sh
# 跑团完整回归：真实服务验收、网页导航回归及小程序页面逻辑回归
npm run test:clubs

# 完整真实接口 + 浏览器布局 + 点击旅程
node design/previews/club-live-acceptance.cjs

# 只执行真实接口（不启动 Chrome）
node design/previews/club-live-acceptance.cjs --api-only

# 接口后只走浏览器点击，不重复全页面扫描
node design/previews/club-live-acceptance.cjs --journeys-only

# 小程序页面逻辑；全客户端回归；小程序原生离线编译；网页构建
node design/previews/mini-club-redesign-regression.cjs
npm run test:client
npm run test:mini
npm run build
```

默认浏览器路径为 macOS Chrome；可用 `CHROME_PATH` 覆盖。默认临时 Vite 端口为 5175，可用 `MARATHON_LIVE_PREVIEW_PORT` 覆盖。不要把脚本改成连接已有业务数据库。

## 本轮发现与闭环

- 多年未结束的旧活动不能计为「我的待参加」或长期占据下一场；新版过滤与入口结果列表采用同一口径，并有额外页面导航回归。
- 切换跑团后，旧请求晚到不能把旧会费/成员/活动回填；授权失败不能继续显示缓存的团内资料。两端分别检查与回归。
- 网页队内赛/接龙的通用输入框 CSS 曾影响 radio 尺寸；已限定输入类型，真实点击选项回归覆盖。
- 相册视频空列表应使用视频文案；按钮使用布局居中；分享长文及低频管理折叠但保留报名/提交入口。
- 相册上传失败后刷新列表仍保留具体错误；小程序照片接入微信原生预览。原生预览调用由页面逻辑回归覆盖，真机体验仍需下方项目验收。
- 队内赛组织者可选择已报名成员代录成绩；没有选人时阻止提交，避免把成绩记到错误成员。小程序页面逻辑回归覆盖这两个分支。

补充的 [网页导航回归](./previews/club-navigation-regression-report.json) 使用内存 mock，覆盖三个视口下 12 项导航、筛选、分享与迟到响应检查；它与本文件的真实服务验收报告分别记录，不混记为真实接口测试。

以上具体用例状态以报告和对应客户端回归为准。发现新的功能失败时，记录修复与复测结果，不能仅调整测试跳过失败。
